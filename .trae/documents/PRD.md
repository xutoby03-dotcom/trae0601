## 1. 产品概述

桌游借用清单是一款专为桌游爱好者与桌游借出管理者设计的全流程桌游借还管理工具，解决桌游借出后配件丢失、归还逾期、盒况不清等核心痛点。
- 目标用户：拥有多款桌游的个人玩家、桌游吧经营者、社团活动组织者
- 核心价值：确保每款桌游配件完整可查、借还流程清晰可追溯、逾期/缺件自动预警

## 2. 核心功能

### 2.2 功能模块

1. **首页仪表盘**：逾期未还提醒、配件不全警告、最近想玩的游戏、借阅统计
2. **游戏档案页**：游戏名称、人数范围、时长、配件清单、盒况评级、封面照片
3. **借出登记页**：借用人、归还日期、押金、借出前配件确认清单
4. **归还检查页**：逐项勾选牌/骰子/说明书/计分板等配件，缺件自动生成补件记录
5. **补件记录页**：缺件详情、关联游戏与借用人、补件状态追踪

| 页面名称 | 模块名称 | 功能描述 |

## 3. 核心流程

借出流程：用户选择游戏 → 填写借用人、归还日期、押金 → 逐项确认配件完好 → 生成借出记录
归还流程：选择借出记录 → 逐项勾选配件归还情况 → 标记缺件 → 自动生成补件记录 → 更新游戏配件状态

    "归还时配件检查" --> "配件是否齐全?"
    "配件是否齐全?" -->|"齐全"| "完成归还"
    "配件是否齐全?" -->|"缺件"| "生成补件记录"
    "生成补件记录" --> "完成归还"

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深棕色 (#3E2723) + 暖金色 (#D4A84B)，呼应桌游木质与金属质感的经典美学
- 辅助色：象牙白 (#FAF3E0)、墨绿 (#2E5D4B)、砖红 (#B5544A)
- 按钮风格：圆角微凸3D按钮，带细微阴影，木质纹理感
- 字体：标题使用衬线体营造经典桌游氛围，正文使用清晰无衬线体保证可读性
- 布局：卡片式布局，模拟桌游卡片质感，圆角+微阴影+纹理边框
- 图标/Emoji：使用桌游主题图标（骰子🎲、卡牌🃏、棋子♟️），增强趣味性

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|---------|
| 首页仪表盘 | 逾期未还卡片 | 暗红警告色卡片，显示游戏名、借用人、逾期天数，带脉冲动画 |
| 首页仪表盘 | 配件不全警告 | 橙色警示卡片，显示游戏名与缺件数 |
| 首页仪表盘 | 最近想玩 | 横向滚动封面卡片，带游戏名与时长标签 |
| 首页仪表盘 | 借阅统计 | 双列排行：左侧借最多的人，右侧最容易少件的游戏 |
| 游戏档案页 | 游戏封面 | 大尺寸封面展示，带盒况徽章 |
| 游戏档案页 | 配件清单 | 表格式清单，每行带图标+名称+数量 |
| 借出登记页 | 配件确认 | 勾选列表，每项带配件图标与状态标签 |
| 归还检查页 | 逐项勾选 | 分组卡片，卡牌/骰子/说明书/计分板各有勾选区域 |
| 补件记录页 | 记录列表 | 时间线式排列，带状态标签与关联信息 |

### 4.3 响应式设计

- 桌面端优先设计，三栏/两栏布局展示信息密度
- 平板端自适应双栏布局
- 移动端单栏布局，卡片纵向堆叠，触控优化增大点击区域
