## 1. 产品概述

早餐店早高峰预订备餐系统——解决老板娘靠脑子记单容易弄混的痛点。用系统管理商品档案、接收顾客预订单、厨房看板按取餐时间排优先级、库存不足自动拦单，并统计每日高峰时段和热门加料。

- **目标用户**：早餐店老板/店员，早高峰期间需快速录入、查询、备餐
- **核心价值**：告别纸笔记单，减少出错率，提升备餐效率和顾客满意度

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 店主/店员 | 直接访问 | 商品管理、接单、厨房看板、库存管理、统计分析 |
| 顾客（模拟） | 下单页面 | 浏览商品、提交预订单 |

### 2.2 功能模块

1. **商品管理页**：商品列表、新增/编辑商品（名称、口味、可选加料、备餐时长、库存数量、照片）
2. **下单页**：选择商品及加料、填写取餐时间、手机号后四位、备注、支付状态
3. **厨房看板页**：按取餐时间排序的订单队列，分区显示（待备餐、已备好、已取走、过时未取）
4. **统计页**：每日各时段订单量趋势、热门加料排行、商品销量排行

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 商品管理 | 商品列表 | 展示所有商品卡片，显示名称、口味、库存状态、照片缩略图 |
| 商品管理 | 新增/编辑商品 | 表单：名称、口味选项、可加料列表、备餐时长（分钟）、库存数量、照片上传 |
| 下单页 | 商品选择 | 分类浏览商品，选择口味和加料，自动检查库存 |
| 下单页 | 订单信息 | 取餐时间选择器、手机号后四位输入、备注文本框、支付状态切换 |
| 厨房看板 | 待备餐区 | 按取餐时间排序的订单卡片，支持标记"已备好" |
| 厨房看板 | 已备好区 | 已完成备餐的订单，支持标记"已取走" |
| 厨房看板 | 已取走区 | 已取餐的订单记录 |
| 厨房看板 | 过时未取区 | 超过取餐时间仍未取走的订单高亮提醒 |
| 统计页 | 时段分布 | 按小时统计订单量的柱状图，标注最拥挤时段 |
| 统计页 | 加料排行 | 各加料被选择的次数排行 |
| 统计页 | 商品销量 | 各商品销量排行 |

## 3. 核心流程

顾客下单流程：选择商品 → 选择口味和加料（系统检查库存） → 填写取餐时间和联系方式 → 提交订单（库存充足则成功，不足则拦截提示）。

厨房备餐流程：订单进入待备餐区（按取餐时间排序） → 店员点击"备好" → 移入已备好区 → 顾客取餐后点击"已取走" → 移入已取走区。超过取餐时间15分钟仍未取走的订单自动移入"过时未取"区。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖橙色（#F97316）——早餐的温暖与活力；辅助色奶油白（#FFFBEB）和深棕色（#44291E）
- **按钮风格**：圆角胶囊按钮，带轻微阴影，点击有下沉反馈
- **字体**：标题使用 Noto Serif SC（温暖有烟火气），正文使用 Noto Sans SC（清晰易读）
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式布局，早高峰信息密度高但不拥挤
- **图标风格**：Lucide 线性图标，配合暖色系

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 商品管理 | 商品列表 | 网格卡片布局，每张卡含商品照片、名称、口味标签、库存数字、编辑/删除按钮 |
| 商品管理 | 编辑弹窗 | 居中模态框，表单字段分组排列，加料用多选标签，备餐时长用滑块 |
| 下单页 | 商品浏览 | 左侧分类标签 + 右侧商品网格，选中商品弹出配置面板 |
| 下单页 | 订单填写 | 底部固定栏显示已选商品摘要，点击展开完整订单表单 |
| 厨房看板 | 订单卡片 | 时间轴布局，卡片按取餐时间排列，不同状态用颜色区分（待备餐-橙、已备好-绿、已取走-灰、过时未取-红） |
| 统计页 | 数据图表 | 大面积留白突出图表，柱状图用渐变色，排行榜用序号标记 |

### 4.3 响应式

- 桌面优先设计，左侧固定导航 + 右侧内容区
- 平板端导航收缩为图标模式
- 移动端底部 Tab 导航，内容区全宽

### 4.4 动效

- 订单状态切换时卡片平滑移动到对应区域
- 新订单进入看板时有入场动画
- 库存不足时商品卡片闪烁警告
- 页面切换使用淡入淡出过渡
