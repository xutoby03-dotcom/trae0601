## 1. 产品概述

二手镜头试拍检查工具，帮助摄影爱好者在购买二手镜头时系统化地完成各项检测，避免因边角模糊、对焦漂移等问题造成损失。通过引导式检查流程、样张放大对比和风险评估，最终生成购买建议和砍价策略。

- **目标用户**：摄影爱好者、二手相机镜头买家
- **核心价值**：标准化镜头检测流程，量化风险，辅助议价决策

## 2. 核心功能

### 2.1 功能模块

1. **首页/镜头信息录入**：输入镜头型号、卡口、卖家报价、成色描述
2. **检查流程页**：按步骤完成7大检查项（外观、镜片霉斑、光圈叶片、自动对焦、无限远、最近对焦、不同光圈样张）
3. **样张对比页**：上传样张，可放大查看中心、边角区域，对比暗角表现
4. **风险标签系统**：为每个发现的问题打风险标签（高/中/低风险）
5. **评估报告页**：生成购买建议、可接受价格区间、砍价理由清单

## 3. 核心流程

用户从首页输入镜头基本信息 → 按检查流程逐项完成检测并上传样张 → 对样张进行放大对比并标记问题区域 → 为发现的问题添加风险标签 → 系统生成最终评估报告（购买建议、价格区间、砍价理由）→ 可导出或保存报告

```mermaid
    F --> G["上传不同光圈样张"]
    G --> H["样张放大对比"]
    H --> I["标记问题与风险标签"]

```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色专业风，以暗灰（#1a1a2e）为底，搭配铜金色（#e8a87c）作为强调色（摄影复古质感）
- **辅助色**：翠绿色（#4ecca3）表示正常通过，橙红色（#e8505b）表示风险警告
- **字体**：标题使用 Playfair Display（衬线体，质感高级），正文使用 DM Sans（现代无衬线，清晰易读）
- **按钮风格**：圆角中等（8px），微立体阴影，hover时有轻微上浮和发光效果
- **布局风格**：卡片式布局，检查流程采用步骤条 + 内容卡片的形式
- **图标风格**：使用 lucide-react 线性图标，统一描边宽度

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 首页 | 镜头信息表单 | 深色卡片、下拉选择器、数字输入框、渐变提交按钮 |
| 检查流程页 | 步骤导航 | 横向步骤条，当前步骤高亮铜金色，已完成步骤打勾绿色 |
| 检查流程页 | 检查项卡片 | 分组卡片，每项带开关/选择器和备注输入框 |
| 样张对比页 | 区域查看器 | 九宫格热点区域，点击放大查看，支持滚轮缩放 |
| 样张对比页 | 对比视图 | 左右分栏或2x2网格对比 |
| 评估报告页 | 风险汇总 | 风险标签云，按严重程度排序 |
| 评估报告页 | 价格评估 | 大号数字展示，价格区间进度条 |

### 4.3 响应式

- 桌面端优先设计（≥1280px）
- 平板端（≥768px）：检查流程改为纵向步骤条
- 移动端（<768px）：简化布局，样张对比改为上下堆叠
