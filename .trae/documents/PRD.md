## 1. 产品概述

二手物品估价集市——一个帮助用户为家中闲置物品智能估价并发布交易的轻量集市平台。用户发布物品时系统自动给出合理价格区间，支持砍价互动与价格追踪，让闲置流转更透明高效。
- 核心用户：有闲置物品需要处置的普通消费者
- 产品价值：降低二手交易定价门槛，提升闲置物品流转效率，帮助用户量化闲置资产

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册，本地模式 | 发布物品、浏览集市、出价砍价、查看统计 |

### 2.2 功能模块
1. **集市首页**: 分类筛选、价格区间筛选、成色筛选、包邮筛选、物品卡片瀑布流
2. **发布页**: 物品信息填写 + 智能估价面板
3. **物品详情页**: 物品信息展示 + 价格曲线 + 砍价模拟区
4. **资产统计页**: 挂售总额、已售金额、回收空间统计

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 集市首页 | 筛选栏 | 分类（数码/家电/服装/书籍/家居/其他）、价格区间、成色、是否包邮筛选 |
| 集市首页 | 物品列表 | 卡片式瀑布流展示，显示图片、名称、价格、成色标签、包邮标识 |
| 发布页 | 物品信息表单 | 填写物品名称、品牌、原价、购买时间、成色（全新/9成新/8成新/7成新/6成新及以下）、配件是否齐全、瑕疵说明、上传照片 |
| 发布页 | 估价面板 | 根据原价×折旧系数×成色系数×市场调整系数自动计算建议价格区间，用户可手动调整最终定价 |
| 物品详情页 | 物品信息展示 | 展示所有物品信息、照片轮播、当前价格 |
| 物品详情页 | 价格变化曲线 | 展示历史价格变化折线图，每次降价记录节点 |
| 物品详情页 | 砍价模拟区 | 买家出价输入框、出价历史列表、卖家操作（接受/拒绝/备注） |
| 资产统计页 | 挂售统计 | 当前挂售物品数量和总金额 |
| 资产统计页 | 已售统计 | 已卖出物品数量和总金额 |
| 资产统计页 | 回收空间 | 估算回收的物理空间（按物品类型推算） |

## 3. 核心流程

**发布估价流程**: 用户进入发布页 → 填写物品信息 → 估价面板自动计算建议价格区间 → 用户确认或调整价格 → 发布到集市

**砍价互动流程**: 买家浏览集市 → 进入物品详情 → 在砍价区出价 → 卖家查看出价 → 接受（成交）/拒绝/备注回复

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：暖橙 #E8763A（集市活力感）+ 深炭 #1C1C1E（高级质感）
- 辅助色：柔黄 #F5C542（价格/标签）、灰绿 #5BA67C（成色/状态）
- 按钮风格：圆角8px，主按钮有轻微阴影和hover弹起效果
- 字体：Noto Sans SC（正文）+ ZCOOL QingKe HuangYou（标题装饰）
- 布局风格：卡片式布局，顶部固定导航，左侧筛选面板（桌面端），内容区域自适应
- 图标风格：lucide-react线性图标

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 集市首页 | 筛选栏 | 左侧固定面板，分类用图标+文字标签，价格区间用滑块，成色用复选标签 |
| 集市首页 | 物品列表 | 瀑布流双列卡片，卡片含图片、名称、价格（橙色加粗）、成色标签、包邮角标 |
| 发布页 | 物品信息表单 | 分步骤表单，步骤指示器，输入框带图标前缀 |
| 发布页 | 估价面板 | 右侧固定面板，仪表盘式价格区间展示，滑块调整，大字显示建议价 |
| 物品详情页 | 价格曲线 | 面积折线图，价格节点tooltip，降价用箭头标注 |
| 物品详情页 | 砍价区 | 对话气泡式出价列表，底部输入框+出价按钮，卖家操作按钮组 |
| 资产统计页 | 统计卡片 | 大数字卡片+环形图+趋势条 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度1024px完整体验
- 移动端筛选面板收起为底部抽屉，卡片改为单列
