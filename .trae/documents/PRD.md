## 1. 产品概述

手作材料库存盒——专为滴胶、串珠、布艺、模型等手作爱好者打造的材料管理工具。解决手作人材料种类多、收纳散、找料难、算成本烦的核心痛点，让每一颗珠子、每一滴胶水都有据可查。

- 目标用户：热衷手作的创作者，需要管理大量小规格、多品类材料
- 核心价值：可视化收纳定位 + 智能库存追踪 + 项目成本核算 + 采购清单自动生成

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 手作人 | 无需注册，本地使用 | 全部功能 |

### 2.2 功能模块

1. **材料抽屉（首页）**：按收纳容器分区展示，低库存预警，快捷搜索筛选
2. **材料管理**：新增/编辑/删除材料，填写完整属性
3. **颜色搜索**：精确颜色筛选 + 近似颜色搜索（如蓝绿色珠子）
4. **项目管理**：创建作品项目，从库存扣料，自动核算成本
5. **采购清单**：基于低库存和项目缺料自动生成采购建议
6. **材料详情**：使用历史时间线，常用/闲置统计

## 3. 核心流程

### 3.1 材料入库流程
用户打开材料抽屉 → 点击新增材料 → 填写名称、类别、颜色、规格、数量、单位、价格、购买链接、收纳位置 → 保存入库 → 首页抽屉视图自动更新

### 3.2 项目用料流程
用户创建项目 → 添加所需材料及用量 → 系统检查库存是否充足 → 确认扣料 → 库存自动减少 → 使用历史自动记录 → 成本自动计算

### 3.3 采购清单流程
系统检测低库存材料 + 项目缺料 → 自动合并生成采购清单 → 用户可手动调整 → 标记已购 → 已购物料入库

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：温暖的手作感 —— 奶油白底 (#FFF8F0) + 焦糖棕主色 (#8B5E3C) + 薄荷绿点缀 (#6BBF8A)
- **次色调**：柔和的粘土粉 (#E8A0BF) 做警示/强调，深棕 (#5C3D2E) 做文字
- **按钮风格**：圆角胶囊按钮，带微妙阴影，hover 时轻微上浮
- **字体**：标题用 Noto Serif SC（衬线体，手作质感），正文用 Noto Sans SC
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式布局
- **图标风格**：lucide-react 线性图标，温暖配色
- **整体调性**：温暖、手作、有质感，像打开一个精心整理的手工材料柜

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 材料抽屉 | 收纳分区视图 | 三列分区（盒子/格子/袋子），每区可折叠，材料小卡片带颜色标记圆点 |
| 材料抽屉 | 低库存预警 | 顶部醒目横幅，粘土粉背景，显示低库存材料数量，点击展开列表 |
| 材料抽屉 | 筛选栏 | 搜索输入框 + 类别下拉 + 颜色选择器 + 位置下拉 |
| 新增材料 | 表单 | 分组表单卡片（基本信息/颜色规格/收纳信息），色板选择器+HEX输入 |
| 颜色搜索 | 近似色面板 | 大色盘选择目标色，滑块调整色距容差，结果网格展示 |
| 项目列表 | 项目卡片 | 卡片网格，封面色块+项目名+状态标签+成本金额 |
| 项目详情 | 用料清单 | 表格形式，行内显示库存/需用/缺料状态，缺料行高亮 |
| 采购清单 | 采购项列表 | 复选框列表，每项显示材料名+需购量+预估价格，底部汇总 |
| 材料详情 | 使用历史 | 纵向时间线，节点显示日期+项目名+用量 |
| 材料详情 | 统计面板 | 环形图展示使用频率，闲置天数倒计时卡片 |

### 4.3 响应式设计

- 桌面优先设计，1280px+ 最佳体验
- 平板端（768px-1280px）：侧边栏收起为图标模式，卡片改为两列
- 移动端（<768px）：底部Tab导航，单列卡片，筛选收起为抽屉
