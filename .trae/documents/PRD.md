## 1. 产品概述

社区老人手机教学报名系统，帮助社区志愿者高效管理老人手机学习课程。解决传统报名方式信息不全、课程匹配度低、学习进度难追踪的问题。

- 目标用户：社区工作人员、志愿者、参与学习的老年人
- 核心价值：系统化管理老人档案和课程，提升教学效率和老人学习体验

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 管理员/志愿者 | 本地登录 | 全部功能：档案管理、课程管理、报名签到、数据统计 |

### 2.2 功能模块

1. **首页仪表盘**：今日课程、数据概览、快捷操作
2. **老人档案管理**：老人信息的增删改查，含头像、年龄、手机型号等详细信息
3. **课程管理**：课程主题、难度、时间、名额设置
4. **报名管理**：老人报名课程、候补机制、一对一/家属需求
5. **课堂签到**：签到、学习记录、问题跟进
6. **数据统计**：主题需求、重复提问、志愿者课时、上门辅导名单

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 数据概览 | 显示老人总数、课程数、今日签到数、待跟进数 |
| 首页 | 今日课程 | 展示当天的课程列表和快速签到入口 |

| 数据统计 | 上门辅导名单 | 需要上门辅导的老人列表 |

## 3. 核心流程

### 3.1 报名流程
志愿者录入老人档案 → 创建课程 → 老人选择课程报名 → 名额满自动进入候补 → 开课前通知

### 3.2 课堂流程
老人签到 → 课程进行中记录学习内容 → 记录遇到的问题 → 课后填写跟进计划

```mermaid
flowchart LR
    A["录入老人档案"] --> B["创建课程"]
    B --> C["老人报名"]
    C --> D{"名额是否已满"}
    D -- "否" --> E["报名成功"]
    D -- "是" --> F["进入候补队列"]
    F --> G["有人取消时自动递补"]
    E --> H["课堂签到"]
    H --> I["记录学习内容"]
    I --> J["记录问题和跟进计划"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：温暖的橙红色系 (#FF6B35)，传递关怀和活力
- **辅助色**：温暖的米黄色背景，柔和的绿色表示成功/正常状态
- **按钮风格**：大圆角按钮，尺寸偏大，适合老年人和工作人员操作
- **字体**：思源黑体 / Noto Sans SC，大号字体，高对比度
- **布局风格**：卡片式布局，大间距，内容清晰易读
- **图标风格**：线性图标，简洁明了，尺寸偏大

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 数据概览 | 四色统计卡片，大数字展示，图标+文字 |
| 首页 | 今日课程 | 时间轴样式课程卡片，状态标签 |
| 老人档案 | 列表 | 头像+基本信息卡片，搜索框+筛选标签 |
| 老人档案 | 详情 | 左侧头像区，右侧信息分组展示 |
| 课程管理 | 列表 | 课程卡片网格，主题标签，名额进度条 |
| 签到记录 | 表单 | 大输入框，多选标签，日期选择器 |
| 数据统计 | 图表 | 柱状图、饼图，配色温暖柔和 |

### 4.3 响应式
- 桌面端优先，适配1280px以上屏幕
- 支持平板设备横屏使用
- 触控区域不小于44x44px
- 字体最小不低于14px，主要文字16px以上

### 4.4 适老化设计
- 大号字体和按钮
- 高对比度配色
- 清晰的图标辅助
- 简洁的操作流程
- 重要操作二次确认
