## 1. 产品概述

烘焙失败复盘本——一款专为烘焙爱好者打造的失败记录与改良追踪工具。帮助用户系统记录每次烘焙的配方细节与失败现象，基于规则智能推理可能原因，支持配方版本迭代与多版本对比，让每一次"翻车"都成为进步的阶梯。

- 核心痛点：烘焙失败后靠记忆复盘，同样错误反复犯；配方调整无记录，改良无从追溯
- 目标用户：家庭烘焙爱好者、烘焙入门新手

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 单用户 | 无需注册 | 全部功能 |

### 2.2 功能模块

1. **首页**：按最近失败、待复盘、已成功改良分组展示烘焙记录，快速入口
2. **烘焙记录页**：新建/编辑一次烘焙记录，填写作品、配方、环境、照片与结果
3. **失败分析页**：选择失败问题标签，系统基于规则推理可能原因与建议
4. **版本管理页**：查看同一作品的配方版本链，记录每次调整内容
5. **版本对比页**：并排对比多个版本的照片与口感评分
6. **统计页**：最常失败原因、作品成功率排行、月度材料浪费统计

## 3. 核心流程

用户打开应用→首页查看失败记录→点击"新建记录"→填写烘焙详情→标记结果为"失败"→选择失败问题标签→系统推理可能原因→标记为"待复盘"→后续调整配方创建新版本→对比版本照片与评分→标记为"已成功改良"→查看统计页了解整体情况

```mermaid
    "新建烘焙记录" --> "填写配方详情"

    "系统推理可能原因" --> "标记待复盘"
    "标记待复盘" --> "调整配方创建新版本"
    "调整配方创建新版本" --> "版本对比"
    "版本对比" --> "成功改良"
    "成功改良" --> "统计页"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：暖棕色(#8B5E3C) + 焦糖色(#D4A574)，搭配奶油白(#FFF8F0)背景
- 辅助色：失败红(#E74C3C)、成功绿(#27AE60)、待复盘琥珀(#F39C12)
- 按钮风格：圆角(12px)，微阴影，温暖触感
- 字体：展示字体使用 Playfair Display，正文使用 Noto Sans SC
- 布局风格：卡片式布局，温暖纸张质感背景
- 图标风格：手绘风格线性图标（lucide-react）
- 整体氛围：像一本温暖的烘焙笔记本，略带手账感

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 最近失败 | 横向滚动卡片，焦糖色边框，显示作品缩略图+问题标签 |
| 首页 | 待复盘 | 竖向列表，琥珀色标签，左侧时间线标记 |
| 首页 | 已成功改良 | 卡片网格，绿色徽章，显示版本数 |
| 烘焙记录页 | 表单 | 分区卡片式表单，温暖背景色，圆角输入框 |
| 烘焙记录页 | 照片上传 | 虚线框拖拽区，缩略图网格 |
| 失败分析页 | 问题标签 | 胶囊标签，选中态加深色+勾选图标 |
| 失败分析页 | 原因卡片 | 渐变边框卡片，灯泡图标，可能原因+建议 |
| 版本管理页 | 时间线 | 竖向时间线，节点为版本号，连线为渐变色 |
| 版本对比页 | 对比视图 | 左右分栏，顶部版本选择器，照片等高排列 |
| 统计页 | 图表区 | 暖色系柱状图+饼图，卡片容器 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1024px
- 平板端：卡片从3列变2列
- 移动端：单列布局，底部Tab导航，版本对比改为上下排列
