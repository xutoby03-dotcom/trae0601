## 1. 产品概述

露营装备借用清单是一款面向朋友间共享露营装备的工具型 Web 应用。解决的核心问题是：朋友之间借帐篷、炉具、灯、桌椅等装备时，容易遗忘谁借了什么、该还什么、缺少什么必需品。

- 目标用户：经常组织露营活动的朋友圈子、户外爱好者小组
- 核心价值：让装备借用有据可查、出发前清单一目了然、归还时状态清晰、逾期自动提醒

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 装备管理员 | 拥有装备的人 | 管理装备库、登记借出/归还、导出清单 |
| 借用人 | 借装备的朋友 | 查看装备状态、查看自己的借用记录 |

> 本应用为轻量工具，不做用户注册登录，通过本地数据管理。

### 2.2 功能模块

1. **装备库管理页**：左侧装备库面板，展示所有装备的照片、分类、数量、状态、归还日期、损耗备注
2. **露营清单页**：右侧本次露营清单面板，拖拽装备添加，自动检测缺少的必需品
3. **借出登记**：登记借给谁、计划归还日期、是否收取押金、逾期标红提醒
4. **归还登记**：勾选是否完好归还，损坏时记录维修费用和损坏描述
5. **场景清单生成**：按露营场景（山里过夜、海边烧烤、亲子露营）一键生成推荐装备清单
6. **导出检查表**：导出出发前检查表，支持打印或分享到群聊

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 左侧装备库 | 展示装备卡片列表（照片、名称、分类、数量、状态标签），支持按分类筛选，点击可查看详情和损耗备注 |
| 主页面 | 右侧露营清单 | 拖拽区域，展示本次已选装备，底部显示缺少的必需品提醒（睡袋、防潮垫、头灯、垃圾袋等） |
| 主页面 | 借出登记弹窗 | 填写借用人姓名、计划归还日期、押金金额，确认后装备状态变为"借出" |
| 主页面 | 归还登记弹窗 | 勾选是否完好、如有损坏填写损坏描述和维修费用，确认后装备状态变为"可用" |
| 主页面 | 逾期提醒条 | 顶部或清单中标红显示逾期未还的装备 |
| 场景页面 | 场景选择 | 三个场景卡片：山里过夜、海边烧烤、亲子露营，点击生成对应清单 |
| 场景页面 | 场景清单预览 | 展示推荐装备列表，可一键添加到本次露营清单 |
| 导出页面 | 出发前检查表 | 表格形式展示所有已选装备，含勾选框、装备名、数量、负责人、备注，支持打印和复制分享 |

## 3. 核心流程

**主流程**：用户打开应用 → 浏览左侧装备库 → 将需要的装备拖入右侧清单 → 系统自动检测缺少的必需品 → 按需补充 → 登记借出信息 → 出发前导出检查表

**借还流程**：装备借出时登记借用人、归还日期、押金 → 系统在清单中标记借出状态 → 逾期自动标红提醒 → 归还时检查完好性 → 损坏则记录维修费用

**场景生成流程**：选择露营场景 → 系统生成推荐清单 → 用户可修改增删 → 一键添加到本次露营清单

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：自然户外风，森林绿 + 大地色系，营造露营氛围
- **主色**：深森林绿 `#2D5016`，辅以暖棕色 `#8B6914`
- **强调色**：日落橙 `#E87040` 用于提醒和关键操作
- **背景**：米白色 `#F5F0E8` 带微妙纹理，如纸张质感
- **按钮风格**：圆角（8px），轻微阴影，hover 时微微上浮
- **字体**：标题使用 `Playfair Display` 衬线体增添品质感，正文使用 `DM Sans` 无衬线体保证可读性
- **布局**：左右双栏布局，左侧装备库约 60% 宽度，右侧清单约 40%
- **图标**：使用 lucide-react 图标库，线框风格
- **卡片**：装备卡片带圆角和柔和阴影，hover 时边框高亮

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 主页面 | 左侧装备库 | 卡片网格布局，每张卡片含装备照片、名称、分类标签、数量、状态徽章，顶部有分类筛选栏 |
| 主页面 | 右侧露营清单 | 纵向列表，每项含拖拽手柄、装备名、数量调节、删除按钮，底部有缺少必需品提醒区（橙色警告卡片） |
| 主页面 | 借出登记弹窗 | 居中模态框，表单含姓名输入、日期选择器、押金开关和金额输入，底部确认/取消按钮 |
| 主页面 | 归还登记弹窗 | 居中模态框，完好状态勾选、损坏描述文本框、维修费用输入框 |
| 主页面 | 逾期提醒 | 顶部红色横幅，显示逾期装备数量，点击展开详情 |
| 场景页面 | 场景选择 | 三个大卡片横向排列，每个含场景插画图标、场景名称、简短描述 |
| 场景页面 | 场景清单 | 分组列表，按装备分类分组展示推荐装备，带添加按钮 |
| 导出页面 | 检查表 | 打印风格表格，含序号、装备名、数量、负责人、状态勾选框、备注列 |

### 4.3 响应式设计

- 桌面端优先（1440px 基准），左右双栏布局
- 平板端（768px-1024px）改为上下布局
- 移动端（<768px）单列布局，底部标签导航切换装备库和清单

### 4.4 动效设计

- 拖拽时装备卡片半透明跟随鼠标
- 放入清单时有弹性缩放动画
- 逾期提醒条入场时从顶部滑入
- 场景卡片切换时有淡入淡出效果
- 借出/归还弹窗有缩放+淡入动画
