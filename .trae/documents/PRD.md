## 1. 产品概述

小区宠物走失互助墙——一个面向社区居民的宠物走失信息发布与互助平台。用户可以快速发布走失或捡到的宠物信息，通过地图和卡片两种视图浏览，互相提供线索，帮助走失宠物早日回家。

- 解决社区业主群信息刷屏、缺乏结构化展示的问题，让寻宠信息一目了然
- 目标用户：小区居民、宠物主人、热心邻居

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 社区居民 | 无需注册，直接使用 | 发布信息、浏览、提供线索、打印启事 |

### 2.2 功能模块

1. **首页**：地图视图 + 卡片列表视图切换，筛选过滤，快速发布入口
2. **发布页**：走失/捡到宠物信息录入，照片上传，关键信息填写
3. **详情页**：宠物完整信息展示，状态切换，线索留言区，打印启事

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 地图视图 | 基于 Leaflet 地图展示宠物位置标记，红色标记=走失，绿色标记=已找到，蓝色标记=捡到待领，点击标记弹出简要信息卡 |
| 首页 | 卡片列表视图 | 瀑布流/网格卡片展示所有宠物信息，缩略图+名字+品种+状态标签+时间，支持按状态/类型筛选 |
| 首页 | 筛选栏 | 按宠物类型（猫/狗/其他）、状态（寻找中/疑似线索/已团圆）、时间范围筛选 |
| 首页 | 发布按钮 | 浮动操作按钮，点击进入发布页面 |
| 发布页 | 基本信息 | 选择类型（走失/捡到）、宠物名字、品种、毛色、性别、体型描述 |
| 发布页 | 时间地点 | 走失/捡到时间（日期+时间选择器）、最后出现地点（地图选点+文字描述） |
| 发布页 | 联系方式 | 联系人姓名、电话、微信（可选）、酬谢说明（可选） |
| 发布页 | 照片上传 | 支持上传多张照片（最多6张），拍照或相册选取，首张为封面图 |
| 详情页 | 信息展示 | 完整宠物信息、照片轮播、地图定位、联系方式 |
| 详情页 | 状态管理 | 三种状态切换：寻找中 → 疑似线索 → 已团圆，状态变更带时间戳记录 |
| 详情页 | 线索留言区 | 其他用户可留言提供线索，支持上传看到宠物时的照片、填写大概时间和地点描述 |
| 详情页 | 打印启事 | 一键生成寻宠启事海报，包含宠物照片、关键信息、联系方式、二维码 |

## 3. 核心流程

**发布走失宠物流程**：用户点击发布 → 选择"走失"类型 → 填写宠物信息 → 上传照片 → 在地图上标记走失位置 → 填写联系方式 → 确认发布 → 首页地图和卡片同步更新

**提供线索流程**：浏览者查看详情 → 在线索区留言 → 上传看到的照片 → 填写时间和地点 → 宠物状态可能更新为"疑似线索"

**寻回闭环流程**：宠物找到 → 发布者将状态改为"已团圆" → 地图标记变为绿色 → 信息归档

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖橙色（#F97316）作为主色，传达温暖、关怀和紧急感；搭配深灰（#1C1917）和米白（#FAFAF9）
- **辅助色**：走失-红色（#EF4444）、捡到-蓝色（#3B82F6）、已团圆-绿色（#22C55E）
- **按钮风格**：圆角药丸按钮，主按钮填充暖橙，次要按钮描边
- **字体**：标题用 ZCOOL KuaiLe（站酷快乐体）增加亲和感，正文用 Noto Sans SC
- **布局风格**：左侧地图+右侧卡片分栏，移动端切换为标签页
- **图标风格**：Lucide 图标库，线条风格，搭配宠物相关 Emoji

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 首页 | 顶部导航栏 | Logo + 标题 + 导入导出按钮 + 发布按钮，毛玻璃背景，固定顶部 |
| 首页 | 筛选栏 | 水平滚动的状态标签（寻找中/疑似线索/已团圆）+ 宠物类型下拉 + 时间排序 |
| 首页 | 地图视图 | 左侧占60%宽度，Leaflet地图，自定义彩色标记点，点击弹出迷你卡片 |
| 首页 | 卡片列表 | 右侧占40%宽度，垂直滚动卡片列表，每张卡片含封面图+信息摘要 |
| 首页 | 移动端适配 | 地图和卡片上下切换，底部Tab栏切换视图 |
| 发布页 | 表单区 | 居中白色卡片式表单，分步骤/分区填写，地图选点嵌入表单中 |
| 发布页 | 照片上传 | 网格占位框，点击上传，支持拖拽，带预览和删除 |
| 详情页 | 顶部信息卡 | 大图轮播 + 宠物名字 + 状态徽章 + 关键信息网格 |
| 详情页 | 地图定位 | 嵌入小型地图展示走失/捡到位置 |
| 详情页 | 状态时间线 | 横向三步骤指示器，显示状态变更历史 |
| 详情页 | 线索留言区 | 瀑布式留言列表，每条包含头像、时间、文字、照片 |
| 详情页 | 打印按钮 | 固定底部操作栏，暖橙色打印启事按钮 |

### 4.3 响应式设计

- 桌面优先设计（1280px+）
- 平板（768px-1279px）：地图和卡片上下排列
- 手机（<768px）：Tab切换地图/卡片视图，表单全屏，底部操作栏

### 4.4 打印启事海报设计

- A4竖版排版
- 顶部大标题："寻宠启事" / "领养公告"
- 中部：宠物大照片 + 名字品种
- 下方：关键信息网格（毛色/性别/走失时间/地点）
- 底部：联系方式 + 二维码（编码详情页URL）
- 醒目状态色条装饰
