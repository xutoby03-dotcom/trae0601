## 1. 产品概述

实验室耗材领用管理系统，解决实验室手套、枪头、培养皿等耗材经常用完才发现无人补货的问题。面向高校/科研实验室场景，让老师高效管理耗材库存、学生规范领用流程，实现库存预警与消耗统计的全流程数字化管理。

- 核心问题：耗材用完才补、危化品管控不严、消耗数据无追踪
- 目标用户：实验室管理员（老师）、课题组学生

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 管理员（老师） | 系统预设账号 | 录入/编辑耗材、审批领用、补货操作、查看统计 |
| 学生 | 系统预设账号 | 浏览耗材、提交领用申请、查看个人记录 |

### 2.2 功能模块

1. **首页仪表盘**：库存正常、低库存预警、待审批、危化耗材四大分区，全局概览
2. **耗材管理页**：耗材录入/编辑，含规格、单位、库存、最低警戒线、存放柜、是否危化、图片
3. **领用申请页**：学生提交领用，含项目、数量、用途、导师、预计归还/消耗说明
4. **审批管理页**：老师审批领用申请，危化类需二次确认审批
5. **统计分析页**：课题组消耗量、补货频率、易短缺耗材排行

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

**耗材录入流程**：管理员进入耗材管理页 → 填写耗材信息（名称、规格、单位、库存、警戒线、存放柜、危化标记、图片）→ 保存入库 → 首页对应分区更新

**领用申请流程**：学生浏览耗材 → 提交领用申请（项目、数量、用途、导师、归还说明）→ 若为危化品则标记需二次审批 → 管理员在审批页查看 → 普通耗材一次审批通过/驳回 → 危化耗材需二次确认审批 → 审批通过后扣减库存

**库存预警流程**：系统实时检测库存 → 库存低于警戒线 → 首页低库存预警区标红展示 → 管理员点击补货 → 输入补货数量 → 库存更新

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨绿色（#0D3B2E）作为主色，搭配琥珀金（#E5A44D）作为强调色，传递科研实验室的专业与严谨
- **辅助色**：危化警示用鲜红（#DC3545），低库存预警用橙色（#F59E0B），正常状态用翠绿（#10B981）
- **按钮风格**：圆角矩形（8px），危化操作按钮带脉冲动画
- **字体**：标题用 Source Serif 4（学术气质），正文用 DM Sans（清晰可读）
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式分区布局
- **图标风格**：线性图标（Phosphor Icons 风格），危化品使用三角警告图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 首页仪表盘 | 四大分区 | 四宫格布局，每区带图标标题、数量徽章、卡片列表；低库存区卡片红色边框脉冲动画 |
| 耗材管理 | 耗材列表 | 搜索栏 + 筛选标签（全部/低库存/危化）+ 表格（危化行红色左边框）+ 图片缩略图 |
| 耗材管理 | 新增/编辑 | 右侧滑出抽屉表单，图片上传区带拖拽提示，危化开关带确认 |
| 领用申请 | 领用表单 | 居中卡片式表单，耗材选择带搜索下拉，危化品选中后显示醒目提示 |
| 审批管理 | 审批列表 | 待审批卡片列表，危化申请带红色标签和脉冲边框，通过/驳回按钮，危化二次确认弹窗 |
| 统计分析 | 图表区 | 柱状图（课题组消耗）、折线图（补货频率）、排行榜（易短缺耗材），卡片容器 |

### 4.3 响应式

- 桌面优先设计，1280px 以上最佳体验
- 平板端导航栏折叠为底部标签栏
- 移动端表格转为卡片列表
