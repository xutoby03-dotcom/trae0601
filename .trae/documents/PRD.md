## 1. 产品概述

小型展会摊位排期管理系统，面向市集、学校义卖、公司开放日等场景，解决摊位分配混乱、类型冲突、用电超负荷等排期难题。管理员高效创建展会并管控摊位分配，摊主便捷申请摊位并提交需求，系统自动检测冲突并提供实时可视化平面图。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 系统预设账号 | 创建/编辑展会、审核摊位申请、管理布展签到、查看统计 |
| 摊主 | 邮箱注册 | 浏览展会、申请摊位、查看申请状态、布展签到 |

### 2.2 功能模块

1. **场地平面图首页**：可视化场地布局、摊位状态颜色标注、冲突提醒
2. **展会管理页**：创建/编辑展会信息、设置摊位布局、审核申请
3. **摊位申请页**：摊主填写申请信息、查看申请状态
4. **布展管理页**：签到记录、迟到标记、临时换位
5. **统计面板页**：摊位利用率、报名类型分布、迟到统计

## 3. 核心流程

### 3.1 展会创建与摊位分配流程

管理员创建展会 → 设置场地布局和摊位位置 → 发布展会 → 摊主浏览并申请 → 系统自动检测冲突（相邻类型重复/用电超负荷/通道阻挡）→ 管理员审核申请 → 确认或拒绝 → 布展日签到 → 统计分析

```mermaid
flowchart TD
    "管理员创建展会" --> "设置场地与摊位布局"
    "设置场地与摊位布局" --> "发布展会"
    "发布展会" --> "摊主浏览展会"
    "摊主浏览展会" --> "摊主提交申请"
    "摊主提交申请" --> "系统冲突检测"
    "系统冲突检测" --> "管理员审核"
    "管理员审核" --> "批准分配摊位"
    "管理员审核" --> "拒绝申请"
    "批准分配摊位" --> "布展日签到"
    "布展日签到" --> "统计分析"
```

### 3.2 冲突检测流程

摊位申请提交 → 检查相邻摊位商品类型是否重复 → 检查该区域用电是否超负荷 → 检查摊位是否阻挡通道 → 生成冲突报告 → 标记为冲突待处理

```mermaid

    "摊位申请提交" --> "相邻类型检测"
    "摊位申请提交" --> "用电负荷检测"
    "摊位申请提交" --> "通道阻挡检测"
    "相邻类型检测" --> "生成冲突报告"
    "用电负荷检测" --> "生成冲突报告"
    "通道阻挡检测" --> "生成冲突报告"
    "生成冲突报告" --> "标记冲突状态"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深墨绿 (#1B4332) + 暖铜金 (#C77B30) 点缀，营造展会市集的质感氛围
- 辅助色：状态色——绿色空位、琥珀色已申请、蓝色已确认、红色冲突
- 按钮风格：圆角微凸按钮，hover 时微微上浮带阴影
- 字体：标题用 Noto Serif SC（衬线体体现品质感），正文用 Noto Sans SC
- 布局风格：左侧导航栏 + 主内容区，卡片式模块分区
- 图标风格：lucide-react 线性图标，1.5px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|

| 展会管理页 | 创建展会表单 | 分步表单（基本信息→布局设置→规则设定），进度指示器 |

### 4.3 响应式设计

桌面优先设计，平板和移动端适配：平面图在小屏幕下支持缩放和拖拽，表格转为卡片列表

### 4.4 动效设计

- 页面切换：fade + slide 过渡
- 摊位状态变化：色块渐变过渡
- 冲突提醒：脉冲闪烁动画
- 签到按钮：点击后涟漪效果
- 数据图表：入场时逐步绘制动画
