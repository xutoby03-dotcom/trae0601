## 1. 产品概述

拜年礼品清单是一款帮助用户管理春节走亲戚送礼的实用工具，解决"送重复、漏人、超预算"三大痛点。目标用户为春节期间需要走访多位亲戚的家庭，通过数字化管理让拜年送礼井井有条。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 无需注册，本地使用 | 所有功能 |

### 2.2 功能模块

1. **首页**：今日拜访路线、待办提醒、快捷操作入口
2. **亲戚管理**：亲戚信息增删改查、关系标签、忌口备注
3. **礼品管理**：礼品信息增删改查、分类筛选、购买状态追踪
4. **拜访安排**：关联亲戚与礼品、设置拜访日期、记录回礼与红包
5. **统计页**：花费总览、礼品热度、安排进度

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 今日拜访卡片 | 显示今天要拜访的亲戚、需携带的礼品、未购买提醒 |
| 首页 | 智能提醒区 | 重复送礼预警、保质期临近预警、预算超支预警 |
| 首页 | 拜访路线概览 | 按日期排列的拜访日程，支持快速跳转 |
| 亲戚管理 | 亲戚列表 | 展示所有亲戚，支持按关系远近筛选，显示去年所送礼品 |
| 亲戚管理 | 亲戚表单 | 填写称呼、地址、关系远近、去年礼物、忌口、预算 |
| 礼品管理 | 礼品列表 | 展示所有礼品，支持按类别筛选，显示购买状态 |
| 礼品管理 | 礼品表单 | 填写类别、单价、数量、适合人群、保质期、购买渠道 |
| 拜访安排 | 安排列表 | 已安排的拜访计划，关联亲戚与礼品 |
| 拜访安排 | 拜访记录 | 拜访后记录对方回礼、孩子红包金额 |
| 统计页 | 花费总览 | 今年总花费、各亲戚花费占比 |
| 统计页 | 礼品热度 | 最常送的礼品排行 |
| 统计页 | 安排进度 | 已安排/未安排亲戚列表、完成率 |

## 3. 核心流程

**主流程**：用户添加亲戚 → 添加礼品 → 创建拜访安排（关联亲戚与礼品）→ 首页查看今日安排 → 拜访后记录回礼与红包 → 统计页查看总览

**提醒流程**：系统自动检测 → 重复送礼（同一亲戚连续两年送相同礼品）→ 保质期临近（礼品保质期在拜访日期前7天内到期）→ 预算超支（某亲戚实际花费超过预算）

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：中国红（#DC2626）+ 暖金色（#D97706），营造春节喜庆氛围
- **辅色调**：奶白色（#FFFBEB）背景 + 深褐色（#44403C）文字
- **按钮风格**：圆角按钮，主要操作用红色填充，次要操作用金色描边
- **字体**：标题使用衬线体（Noto Serif SC），正文使用无衬线体（Noto Sans SC）
- **布局**：卡片式布局，左侧导航栏 + 右侧内容区
- **图标风格**：线性图标（lucide-react），辅以春节元素装饰（灯笼、红包等用CSS绘制）
- **动效**：页面切换淡入、卡片悬停微浮起、提醒卡片脉冲动画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 今日拜访卡片 | 红色渐变卡片、亲戚称呼大字、礼品清单列表、未购买红色标记 |
| 首页 | 智能提醒区 | 黄色/橙色警告卡片、脉冲动画、点击可跳转处理 |
| 首页 | 拜访路线 | 横向时间轴、日期节点、亲戚头像占位 |
| 亲戚管理 | 亲戚列表 | 关系远近用颜色标签（近亲红/远亲金）、搜索栏、浮动添加按钮 |
| 亲戚管理 | 亲戚表单 | 侧滑面板、分步表单、忌口多选标签 |
| 礼品管理 | 礼品列表 | 类别筛选标签栏、已购/未购状态徽章、价格醒目显示 |
| 礼品管理 | 礼品表单 | 侧滑面板、适合人群多选、保质期日历选择 |
| 统计页 | 花费总览 | 大数字卡片、环形图占比、同比去年 |
| 统计页 | 礼品热度 | 横向柱状图、礼品名称+次数 |
| 统计页 | 安排进度 | 进度条、未安排亲戚红色列表 |

### 4.3 响应式设计

- 桌面优先设计，左侧固定导航栏（240px）
- 平板端导航栏收缩为图标栏（64px）
- 移动端导航栏变为底部标签栏，内容区全宽
- 触摸优化：按钮最小44px点击区域，列表项左滑操作
