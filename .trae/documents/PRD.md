## 1. 产品概述

小区车位临停互让平台——业主空闲车位临时共享给邻居的社区互助工具。解决小区停车位紧张、业主外出时车位闲置浪费的问题，让邻里之间方便、安全地共享停车资源。

- 目标用户：小区业主（车位出租方和停车需求方）
- 核心价值：盘活闲置车位资源，降低邻里停车成本，建立社区信任

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 车位业主 | 手机号注册 | 登记车位、审批申请、查看统计 |
| 停车需求方 | 手机号注册 | 浏览车位、发起申请、标记离开 |

> 注：同一用户可同时拥有两种角色

### 2.2 功能模块

1. **首页**：车位列表分组展示（今晚可用、周末可用、快开始）、安全提醒横幅、搜索筛选
2. **车位登记页**：业主发布空闲车位信息
3. **临停申请页**：需求方填写停车申请
4. **我的车位页**：管理已登记车位、审批/拒绝申请、标记停车结束
5. **统计页**：车位利用率、常借用户、超时记录

## 3. 核心流程

### 3.1 车位共享流程

业主登记空闲车位 → 需求方浏览并选择车位 → 填写临停申请 → 业主收到通知 → 同意/拒绝 → 停车开始 → 停车结束标记 → 双方确认（是否超时/占错位）

```mermaid
flowchart TD
    "业主登记车位" --> "需求方浏览首页"
    "需求方浏览首页" --> "选择车位发起申请"
    "选择车位发起申请" --> "业主审批"
    "业主审批" -->|"同意"| "停车开始"
    "业主审批" -->|"拒绝"| "需求方收到通知"
    "停车开始" --> "停车结束标记"
    "停车结束标记" --> "标记是否超时/占错位"
    "标记是否超时/占错位" --> "统计数据更新"
```

### 3.2 安全提醒流程

用户进入申请页 → 展示安全须知 → 用户确认 → 提交申请 → 超时自动提醒车主

```mermaid
flowchart TD
    "进入申请页" --> "展示安全须知"
    "展示安全须知" --> "用户确认"
    "用户确认" --> "提交申请"
    "提交申请" --> "停车计时开始"
    "停车计时开始" --> "接近超时提醒"
    "接近超时提醒" --> "超时后再次提醒"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：温暖社区感的琥珀橙（#F59E0B）+ 深灰蓝（#1E293B）
- 辅助色：成功绿（#10B981）、警告红（#EF4444）、信息蓝（#3B82F6）
- 按钮风格：圆角胶囊按钮，带微妙阴影
- 字体：Noto Sans SC 作为主字体，搭配一个特色展示字体
- 布局风格：卡片式布局，底部导航栏，顶部安全提醒横幅
- 图标风格：线性图标（Lucide），搭配小面积色块点缀
- 整体风格：温馨社区感，干净易用，像小区公告栏一样亲切

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 安全提醒横幅 | 橙色渐变背景，白色文字，滚动切换不同提醒 |
| 首页 | 今晚可用 | 琥珀色标题标签，白色卡片列表，卡片含楼栋/车位号/时段/状态标签 |
| 首页 | 周末可用 | 蓝色标题标签，同上卡片样式 |
| 首页 | 快开始 | 绿色标题标签，带倒计时角标 |
| 首页 | 筛选栏 | 顶部横向滚动标签筛选器 |
| 车位登记页 | 表单 | 分组表单卡片，开关控件，时段选择器，底部提交按钮 |
| 临停申请页 | 申请表 | 车牌输入框（车牌键盘风格），时长滑块，开关控件 |
| 临停申请页 | 安全须知 | 弹窗确认框，带勾选确认 |
| 我的车位页 | 车位卡片 | 状态标签（空闲/使用中/待审批），操作按钮 |
| 我的车位页 | 审批弹窗 | 申请详情+同意/拒绝按钮 |
| 统计页 | 数据卡片 | 大数字展示利用率，列表展示排行，时间轴展示超时记录 |

### 4.3 响应式设计

- 移动端优先设计（小区场景以手机使用为主）
- 桌面端自适应加宽，卡片网格从单列变多列
- 触摸优化：按钮最小44px点击区域，滑动切换分组

### 4.4 视觉氛围

- 温暖的渐变背景（浅米色到浅灰白）
- 卡片带细微阴影和圆角
- 状态标签用不同颜色区分（空闲=绿，使用中=橙，待审批=蓝）
- 安全提醒区域用醒目但不刺眼的暖橙色
