## 1. 产品概述

生物实验课样本流转系统——用于追踪实验样本从准备室出库、领用、归还到废弃回收的全生命周期，解决样本丢失难追、过期样本误发放、高危样本未授权出库等管理痛点。面向高校生物实验室的教师和实验员。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 实验员 | 管理员分配 | 样本入库、档案管理、统计查看、归还/废弃登记 |
| 教师 | 管理员分配 | 领用审批（高危样本确认）、统计查看 |
| 学生 | 管理员分配 | 领用申请、查看个人领用记录 |

### 2.2 功能模块

1. **样本档案页**：样本登记、编辑、查询、照片上传、状态概览
2. **领用管理页**：领用登记、教师确认、过期/高危校验、领用记录
3. **归还废弃页**：归还登记、废弃登记、污染情况记录、回收确认
4. **统计仪表盘**：消耗量统计、未归还追踪、温度异常告警、废弃原因分析

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 样本档案 | 样本列表 | 按编号/类型/批次/危险等级筛选，展示库存量、状态标签（正常/即将过期/已过期/温度异常） |
| 样本档案 | 样本详情 | 展示编号、类型、批次、保存温度、有效期、危险等级、照片、出入库记录时间线 |
| 样本档案 | 新增/编辑样本 | 表单录入编号、类型、批次、保存温度（范围）、有效期、危险等级（1-5级）、照片上传 |
| 领用管理 | 领用登记 | 填写班级、实验台号、领用学生、数量、领取时间；自动校验过期/高危规则 |
| 领用管理 | 教师确认 | 高危样本（等级≥4）需教师确认才可出库，确认后状态流转 |
| 领用管理 | 领用记录 | 查看历史领用记录，按班级/学生/日期筛选 |
| 归还废弃 | 归还登记 | 记录剩余量、是否有污染、归还人签名 |
| 归还废弃 | 废弃登记 | 记录废弃原因、污染情况、处理方式（焚烧/化学处理/高压灭菌等）、回收人 |
| 统计仪表盘 | 消耗统计 | 按实验课/班级/样本类型统计消耗量，柱状图+趋势图 |
| 统计仪表盘 | 未归还追踪 | 列出所有未归还样本，超期高亮，按学生/班级筛选 |
| 统计仪表盘 | 温度异常 | 展示温度超出保存范围的样本告警列表 |
| 统计仪表盘 | 废弃原因分析 | 饼图展示各废弃原因占比（过期、污染、损坏、实验结束等） |

## 3. 核心流程

**样本全生命周期流程**：入库登记 → 库存待领 → 领用申请 → 规则校验（过期？高危？）→ 教师确认（高危必须）→ 出库 → 实验 → 归还/废弃 → 回收入库或销毁

```mermaid
    "过期校验" -->|"已过期"| "拒绝出库"

    "教师确认" -->|"已确认"| "出库"
    "教师确认" -->|"未确认"| "拒绝出库"
    "出库" --> "实验中"
    "实验中" --> "归还登记"

```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色（#0F766E）+ 琥珀色警示（#D97706）+ 石板灰中性色
- **按钮风格**：圆角（8px）、适度阴影、hover微上浮动效
- **字体**：标题用 Noto Serif SC（衬线，学术感），正文用 Noto Sans SC
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式布局
- **图标**：Lucide React 图标库，线条风格
- **危险等级色标**：1级绿 → 5级红 渐变色标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 样本档案 | 样本列表 | 搜索栏+筛选器组合、状态标签（彩色徽章）、卡片网格/列表切换、悬浮操作按钮 |
| 样本档案 | 新增样本 | 分步表单、照片上传拖拽区、温度范围滑块、危险等级色标选择器 |
| 领用管理 | 领用登记 | 样本扫码/搜索选择、数量步进器、教师确认弹窗（带签名区）、校验提示条 |
| 归还废弃 | 归还/废弃登记 | Tab切换归还/废弃、污染情况勾选+描述、处理方式下拉选择、回收人下拉 |
| 统计仪表盘 | 总览 | 4张统计卡片（数字+图标）、消耗柱状图、未归还表格、废弃原因饼图、温度异常列表 |

### 4.3 响应式设计

- 桌面优先设计，1920px基准宽度
- 平板（768-1024px）导航栏折叠为汉堡菜单
- 手机端（<768px）单列布局，表格转为卡片列表
