## 1. 产品概述

午休躺椅预约管理系统，解决公司午休躺椅按座位抢占、使用后无人收尾的问题。员工可预约躺椅，签到使用，结束时必须确认清洁整理，行政可查看使用数据统计。

- 核心目标：规范躺椅使用流程，确保清洁责任到人，提升办公环境品质
- 目标用户：公司员工（使用者）、行政人员（管理者）
- 核心价值：先到先得的预约机制 + 强制清洁确认闭环 + 信用分约束

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 员工 | 工号登录 | 预约躺椅、扫码签到、结束确认、查看信用分 |
| 行政 | 管理员账号 | 查看统计、管理躺椅、处理异常、查看爽约名单 |

### 2.2 功能模块

1. **预约首页**：日期选择、时段选择、躺椅选择、预约提交
2. **签到与使用**：扫码签到、使用状态展示、结束使用
3. **清洁确认**：5项清洁确认（折叠、靠垫归位、毯子放回、擦拭、损坏报告）
4. **信用分系统**：初始100分，爽约扣10分，低分时限制预约
5. **躺椅详情**：位置、配套物品、清洁状态、照片展示
6. **行政统计**：每日使用率、热门时段、爽约名单、易损部件统计

## 3. 核心流程

### 预约流程
员工选择日期 → 选择半小时时段 → 选择躺椅编号 → 系统校验连续预约时长（≤2小时）→ 校验信用分（≥60分）→ 提交预约 → 预约成功

### 使用流程
预约开始前10分钟可签到 → 扫码/手动签到 → 躺椅状态变为"使用中" → 结束使用 → 清洁确认5项全选 → 如有损坏填写备注 → 提交确认 → 躺椅状态变为"已清洁"可被下次预约

### 爽约处理
预约时间开始后15分钟未签到 → 自动标记为爽约 → 扣信用分10分 → 躺椅释放可被他人预约

### 行政统计
行政登录 → 查看每日使用率图表 → 查看热门时段热力图 → 查看爽约名单 → 查看易损部件统计 → 导出数据（可选）

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深青色 `#0F766E`（专业、稳重），辅助色：暖橙色 `#F97316`（提醒、行动）
- **按钮风格**：圆角8px，悬停有轻微阴影和颜色加深效果
- **字体**：标题使用 `Noto Sans SC` 700，正文使用 `Noto Sans SC` 400/500
- **布局风格**：卡片式布局，干净留白，内容区最大宽度1200px居中
- **图标风格**：使用 Lucide 图标库，线性风格，与文字同色

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|----------|--------|
| 预约首页 | 预约区 | 日期横向滚动选择器、时段网格、躺椅编号卡片、预约确认弹窗 |
| 预约首页 | 状态区 | 个人信用分展示、即将开始预约提醒 |
| 清洁确认页 | 确认清单 | 5个带图标的勾选框、损坏输入框、提交按钮（禁用状态样式） |
| 行政看板 | 统计区 | 卡片式统计指标、使用率折线图、时段热力图、数据表格 |
| 躺椅详情页 | 详情区 | 照片轮播、状态标签、物品清单、清洁历史 |

### 4.3 响应式
- 桌面端：三栏布局（日期选择 + 时段选择 + 躺椅选择）
- 平板端：两栏布局（日期+时段选择 + 躺椅选择）
- 移动端：单列滚动布局，时段和躺椅选择采用紧凑卡片
- 触摸优化：按钮最小高度44px，触控区域充足

### 4.4 动画与交互
- 页面加载：内容区域渐入 + 轻微上移动画
- 选择交互：选中卡片有缩放效果和边框高亮
- 清洁确认：每勾选一项进度条动画增加20%
- 提交反馈：成功/失败弹窗有弹性动画
- 状态变更：使用中状态呼吸灯效果
