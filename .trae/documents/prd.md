## 1. 产品概述

家庭垃圾分类督促台——专为家庭场景设计的垃圾分类管理工具，解决厨余、可回收、有害垃圾混投的日常痛点。通过分类记录、规则提醒、纠错机制和统计排行，帮助全家人养成正确分类习惯。
- 核心目标：让每个家庭成员都能快速识别垃圾类别、按时投放、减少分错率
- 目标用户：有垃圾分类需求的城镇家庭住户（2-6人家庭）

## 2. 核心功能

### 2.1 用户角色
| 角色 | 加入方式 | 核心权限 |
|------|----------|----------|
| 家长（管理员） | 创建家庭 | 管理成员、设置提醒、查看统计、纠正记录 |
| 家庭成员 | 加入家庭 | 添加垃圾记录、查看规则、查看统计 |

### 2.2 功能模块
1. **首页**：今日待扔、攒着等回收、容易分错 三大分组展示，快捷添加垃圾入口，小区垃圾房开放时间提醒
2. **记录页**：拍照/选择垃圾、标记分类、选择投放人、选择垃圾桶类型、纠错功能
3. **规则卡页**：常见易错分类规则卡片、分类百科、搜索规则
4. **统计页**：本周分错次数、可回收攒了多少、谁最常忘记扔厨余、分类正确率趋势

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 今日待扔 | 显示今天需要投放的垃圾列表，按时间排序，支持标记已扔 |
| 首页 | 攒着等回收 | 展示可回收物积攒列表（纸箱、塑料瓶等），显示积攒数量 |
| 首页 | 容易分错 | 展示高频分错垃圾提醒卡片，提醒正确分类 |
| 首页 | 垃圾房提醒 | 显示小区垃圾房开放时段，临近开放时高亮提醒 |
| 首页 | 快捷添加 | 底部浮动按钮，快速添加垃圾记录 |
| 记录页 | 垃圾信息录入 | 输入垃圾名称、选择分类（厨余/可回收/有害/其他）、投放时间、注意事项 |
| 记录页 | 投放人选择 | 选择是哪个家庭成员扔的 |
| 记录页 | 桶类型选择 | 选择扔到哪类垃圾桶 |
| 记录页 | 纠错标记 | 管理员可标记错误分类并纠正，记录分错次数 |
| 规则卡页 | 易错规则卡片 | 如"湿纸巾不是可回收"、"牛奶盒要冲洗"、"外卖盒先清残渣"等 |
| 规则卡页 | 分类搜索 | 搜索垃圾名称查看正确分类 |
| 规则卡页 | 规则收藏 | 收藏常用规则卡片 |
| 统计页 | 本周分错统计 | 显示本周分类错误次数及趋势 |
| 统计页 | 可回收积攒量 | 显示可回收物累计数量和重量 |
| 统计页 | 家庭排行 | 谁最常忘记扔厨余、谁分类最准确 |
| 统计页 | 垃圾房开放设置 | 设置小区垃圾房开放时段，开启提醒 |

## 3. 核心流程

用户打开应用 → 首页看到今日待扔/回收积攒/易错提醒 → 点击快捷添加 → 选择垃圾、分类、投放人、桶类型 → 保存记录 → 管理员发现分错 → 纠正记录并标记 → 统计页更新分错数据

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：自然绿 (#2D6A4F) + 暖棕 (#8B6914) + 警示红 (#E63946)
- 辅助色：可回收蓝 (#457B9D)、有害红 (#E63946)、厨余绿 (#52B788)、其他灰 (#6C757D)
- 按钮风格：圆角大按钮，微阴影，点击有弹性动效
- 字体：标题用 ZCOOL KuaiLe（有趣感），正文用 Noto Sans SC
- 布局：移动端优先卡片式布局，顶部 Tab 导航
- 图标/Emoji：每个分类用专属图标 🥬厨余 ♻️可回收 ☠️有害 🗑️其他

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 首页 | 今日待扔 | 绿色主题卡片列表，左侧分类图标，右侧时间标签，滑动标记已扔 |
| 首页 | 攒着等回收 | 蓝色主题卡片，显示积攒数量角标，堆叠动画 |
| 首页 | 容易分错 | 橙色警示卡片，错→对对比展示，翻转动画揭示正确答案 |
| 首页 | 垃圾房提醒 | 顶部横幅，倒计时显示距下次开放时间，脉冲动画 |
| 记录页 | 垃圾信息录入 | 大图标分类选择器（4个大色块），表单输入，底部确认按钮 |
| 记录页 | 投放人选择 | 圆形头像选择器，选中高亮描边 |
| 记录页 | 纠错标记 | 红色警告图标，纠正弹窗选择正确分类 |
| 规则卡页 | 规则卡片 | 翻转卡片正面"你以为"/背面"实际上"，渐变背景 |
| 规则卡页 | 分类搜索 | 顶部搜索框，实时下拉匹配结果 |
| 统计页 | 数据看板 | 环形图、柱状图，绿色主题数据卡片 |
| 统计页 | 家庭排行 | 头像+进度条排行，冠军奖杯动画 |

### 4.3 响应式设计
- 移动端优先（375px起），平板适配（768px），桌面端（1024px+）双栏布局
- 触控优化：大按钮、滑动操作、长按快捷操作
