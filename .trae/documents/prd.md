## 1. 产品概述

接机牌轮播屏是一款面向机场接机司机的专用大屏显示工具。司机提前录入乘客姓名、航班号、到达口、语言和备注信息后，页面按航班落地时间自动轮播大字接机牌，避免同时接多航班时拿错纸牌的尴尬。

- 解决问题：司机同时接多个航班时纸质接机牌容易拿错、切换不及时、夜间看不清
- 目标用户：机场接机司机、酒店接机人员、地接社司机

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 接机司机 | 无需注册，本地使用 | 录入/编辑/删除乘客信息，控制轮播，切换模式 |

### 2.2 功能模块

1. **轮播大屏页**：全屏大字接机牌，按航班落地时间自动切换
2. **乘客管理页**：录入、编辑、删除乘客信息
3. **快捷详情页**：快速查看电话和停车位置备注

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 轮播大屏页 | 接机牌展示 | 全屏显示当前乘客姓名（超大字）、航班号、到达口、欢迎语（按语言）、高亮边框，自动按落地时间轮播 |
| 轮播大屏页 | 轮播控制 | 显示轮播进度条、当前/总数、暂停/继续按钮、手动上下切换 |
| 轮播大屏页 | 夜间模式 | 切换深色背景+高对比度文字，适合夜间航站楼使用 |
| 轮播大屏页 | 防误触锁定 | 锁定屏幕触控，防止误操作切换，需长按解锁 |
| 轮播大屏页 | 延误处理 | 标记延误航班后，该接机牌自动排到轮播队列末尾 |
| 轮播大屏页 | 已接移除 | 一键标记已接到乘客，从轮播中移除 |
| 乘客管理页 | 乘客列表 | 显示所有乘客卡片，按落地时间排序，支持延误/已接状态标记 |
| 乘客管理页 | 录入表单 | 输入乘客姓名、航班号、到达口、语言（中/英/日/韩/其他）、落地时间、联系电话、停车位置备注 |
| 快捷详情页 | 详情浮层 | 从轮播大屏点击/滑动呼出，显示电话号码（可点击拨打）和停车位置备注 |

## 3. 核心流程

司机进入应用 → 录入多位乘客信息 → 进入轮播大屏模式 → 系统按落地时间自动切换接机牌 → 延误航班降级 → 接到乘客后移除 → 全部接完结束

    K -->|"否"| L["全部接完"]

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：航空蓝 (#0A1628) 深色基底 + 亮橙 (#FF6B2B) 高亮强调色
- **辅助色**：白 (#FFFFFF) 主文字、灰蓝 (#8B9CB6) 次要文字、翠绿 (#00C48C) 成功状态
- **边框风格**：高亮粗边框（4px 渐变发光边框），夜间模式下增强发光效果
- **字体**：乘客姓名使用超大粗体（120px+），航班号和到达口大字（48px+），备注小字（24px）
- **布局**：全屏居中布局，信息层级分明，远距离可辨识
- **动效**：接机牌切换时淡入淡出 + 轻微缩放，进度条平滑过渡

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 轮播大屏页 | 接机牌展示 | 全屏深色背景、渐变发光边框、超大姓名、航班号、到达口、语言欢迎语、切换动画 |
| 轮播大屏页 | 底部控制栏 | 轮播进度指示器、暂停/播放按钮、上一个/下一个、夜间模式切换、锁定按钮、已接按钮 |
| 乘客管理页 | 乘客列表 | 卡片式列表，每张卡片显示姓名+航班+时间+状态标签，右滑删除 |
| 乘客管理页 | 录入表单 | 底部抽屉式表单，字段清晰分组 |
| 快捷详情页 | 详情浮层 | 半透明遮罩 + 居中卡片，电话号码大字可点、停车位置备注高亮 |

### 4.3 响应式设计

- 桌面优先设计，主要在平板和手机横屏使用
- 平板横屏为最佳显示比例
- 手机竖屏时字号适当缩小但仍保持可读性
- 触控区域最小 44×44px，大按钮为主

### 4.4 夜间模式

- 深色背景 (#050D1A)，文字高亮白色
- 边框发光效果增强（box-shadow + glow）
- 自动检测系统暗色模式偏好，也可手动切换
- 过渡动画平滑切换
