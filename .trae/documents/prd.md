## 1. 产品概述

老人助听器电量提醒应用——帮助老年用户及其家人实时管理助听器电量、佩戴状态与维护记录，避免出门后才发现没电的尴尬局面。通过智能分组提醒和统计分析，让助听器使用更安心。

- 核心目标：让老人和家属再也不用担心助听器突然没电，通过及时提醒和完整记录提升助听器使用体验
- 目标用户：使用助听器的老年人及其照护家属

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 主要用户 | 使用助听器的老人 | 添加助听器、记录每日状态、查看提醒 |
| 家属用户 | 照护老人的家人 | 设置提醒规则、查看统计报告、远程关注 |

### 2.2 功能模块

1. **首页**：今日充电提醒、快换电池提醒、异常反馈分组展示，快速掌握全局
2. **助听器管理页**：添加/编辑助听器设备信息（左右耳、型号、电池类型等）
3. **每日记录页**：记录佩戴时长、剩余电量、是否充电、有无啸叫或听不清
4. **提醒设置页**：家人设置提醒规则（睡前充电、出门前检查备用电池等）
5. **维护记录页**：清洁滤网、更换耳塞、维修记录
6. **统计页**：平均续航、哪只耳朵问题多、本月忘充电次数

## 3. 核心流程

**日常使用流程**：用户打开应用 → 首页看到分组提醒（充电/换电池/异常）→ 点击快速记录今日状态 → 查看提醒并执行（充电/换电池）→ 完成后标记已完成

**添加设备流程**：进入助听器管理 → 点击添加 → 填写设备信息（左右耳/型号/电池类型/充电盒/购买日期/保修电话）→ 保存

**家属提醒流程**：家属进入提醒设置 → 新建提醒（类型/时间/关联设备）→ 提醒生效后在首页显示

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：温暖的琥珀橙（#E8913A），传递关怀与温暖感；辅色为深靛蓝（#2D3A4A），营造稳重安心感
- 按钮风格：大圆角（12px），带轻微阴影，方便老人点击
- 字体：使用 Noto Sans SC 中文字体，正文 16px 以上，标题加粗醒目，确保老年人可读
- 布局风格：卡片式布局，左侧导航栏，大间距，留白充足
- 图标风格：使用 Lucide 图标库，线性风格，尺寸偏大（20-24px）
- 整体风格：温暖、简洁、大字号、高对比度，适配老年人使用习惯

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 首页 | 今日充电提醒 | 橙色卡片，电池图标+百分比进度条，大字号电量数字 |
| 首页 | 快换电池提醒 | 红色警告卡片，闪烁动画提示紧急程度 |
| 首页 | 异常反馈 | 黄色警示卡片，异常类型标签 |
| 首页 | 快捷操作 | 底部固定大按钮，一键记录充电状态 |
| 助听器管理 | 设备列表 | 左耳/右耳分栏展示，卡片内含设备缩略信息 |
| 助听器管理 | 添加表单 | 大输入框、下拉选择器，分步引导填写 |
| 每日记录 | 记录表单 | 滑块输入电量百分比、数字输入佩戴时长、开关切换是否充电 |
| 提醒设置 | 提醒规则 | 开关卡片，时间选择器，关联设备标签 |
| 维护记录 | 时间线 | 纵向时间线布局，维护类型用颜色区分图标 |
| 统计 | 图表区 | 柱状图展示续航对比、饼图展示异常分布、数字卡片展示忘充次数 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px 适配最佳
- 平板端（768px-1024px）侧边栏收起为底部导航
- 移动端（< 768px）全底部导航，卡片单列排列
- 所有可点击元素最小 44px 触控区域，方便老人操作
