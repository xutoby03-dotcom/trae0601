## 1. 产品概述

旧手机回收估价册——帮助用户盘点家中闲置旧手机，基于本地规则快速估价，对比各回收渠道报价，记录成交与处理方式，让每一台老手机都物尽其用。
- 解决"抽屉里旧手机到底值不值钱"的痛点，提供透明的估价逻辑和多平台报价对比
- 面向有旧手机闲置的普通消费者，目标是从信息不对称中为用户争取最大回收价值

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 无需注册，本地使用 | 添加/编辑/删除手机、查看估价、记录报价与成交、查看统计 |

### 2.2 功能模块

1. **首页（手机列表）**：按分组展示所有旧手机（可回收 / 建议自用备机 / 只适合拆件），快速总览估价区间
2. **添加/编辑手机页**：填写手机详细信息（品牌、型号、容量、颜色、购买年份、屏幕状态、电池健康、是否进水、配件、照片），实时估价
3. **手机详情页**：查看估价区间与扣分明细，管理平台报价，记录成交信息
4. **统计页**：家里清出了多少钱、缺资料的手机、最影响价格的问题类型

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 分组导航 | 三个分组标签切换：可回收、建议自用备机、只适合拆件 |
| 首页 | 手机卡片列表 | 每张卡片显示品牌型号、容量颜色、估价区间、状态标签，点击进入详情 |
| 首页 | 快速估价入口 | 悬浮按钮，一键添加新手机 |
| 添加/编辑手机页 | 基础信息 | 品牌（下拉）、型号（输入）、容量（下拉）、颜色（选择）、购买年份（年份选择器） |
| 添加/编辑手机页 | 状态评估 | 屏幕状态（完好/划痕/碎裂）、电池健康（百分比滑块）、是否进水（开关）、账号是否退出（开关） |
| 添加/编辑手机页 | 配件与照片 | 配件多选（充电器/数据线/原装盒/耳机/贴膜/手机壳）、拍照/选图上传 |
| 添加/编辑手机页 | 实时估价 | 填写过程中实时显示估价区间和扣分项提示 |
| 手机详情页 | 估价报告 | 估价区间、各扣分项及其影响金额、增值项（配件等） |
| 手机详情页 | 平台报价 | 添加不同平台报价（上门回收/邮寄回收/线下门店），含平台名称、报价、备注 |
| 手机详情页 | 成交记录 | 记录最终成交价、成交平台、处理方式（回收/转卖/捐赠/留用拆件） |
| 统计页 | 总览卡片 | 已回收总金额、待处理手机数、平均回收单价 |
| 统计页 | 缺资料提醒 | 列出信息不完整的手机，提示补充哪些字段 |
| 统计页 | 问题影响排行 | 各类问题（屏幕碎、进水、电池差等）对价格的平均影响幅度 |

## 3. 核心流程

用户打开应用 → 首页看到分组手机列表 → 点击"添加手机" → 填写品牌型号等基础信息 → 选择屏幕状态、电池健康等评估项 → 实时查看估价区间和扣分提示 → 保存手机 → 在详情页查看完整估价报告 → 添加各平台报价进行对比 → 最终记录成交价和处理方式

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深绿 #1B4332 搭配薄荷绿 #52B788，象征环保回收；辅助色暖橙 #F77F00 用于价格强调
- **按钮风格**：圆角胶囊按钮，主按钮带轻微投影，次按钮为描边风格
- **字体**：标题使用 Noto Serif SC 衬线体营造"册"的质感，正文使用 Noto Sans SC
- **布局风格**：卡片式布局，顶部标签导航，大量留白，信息层次分明
- **图标风格**：线条图标，2px 描边，与环保主题一致的自然风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 分组导航 | 顶部三个胶囊标签，选中态填充深绿底白字，未选中描边 |
| 首页 | 手机卡片 | 白色圆角卡片，左侧手机缩略图，右侧品牌型号+估价区间+状态小标签 |
| 首页 | 添加按钮 | 右下角悬浮圆形按钮，深绿底色+白色加号图标，hover放大动画 |
| 添加/编辑页 | 表单区 | 分段式表单，每段带小标题（基础信息/状态评估/配件照片），输入框带图标 |
| 添加/编辑页 | 估价预览 | 底部固定横幅，实时显示估价区间，扣分项红色标注 |
| 详情页 | 估价报告 | 顶部大号估价区间数字，下方扣分明细用红色箭头标注，增值项绿色箭头 |
| 详情页 | 平台对比 | 三列对比卡片（上门/邮寄/门店），每列显示平台名和报价，最高价高亮 |
| 详情页 | 成交记录 | 成交标签页，含成交价、平台、日期、处理方式的标签组合 |
| 统计页 | 总览区 | 三个大数字卡片横排，数字带计数动画 |
| 统计页 | 缺资料列表 | 黄色警告背景列表，每项显示手机名+缺什么字段 |
| 统计页 | 问题排行 | 横向柱状图，柱体颜色从绿到红渐变，表示影响程度 |

### 4.3 响应式设计

- 桌面优先设计，最大宽度 1200px 居中
- 平板：卡片从双列变单列，统计图自适应宽度
- 手机：底部导航替代侧边导航，表单全宽，悬浮按钮位置调整
