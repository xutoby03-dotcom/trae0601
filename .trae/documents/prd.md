## 1. 产品概述

公司访客预约台——为企业前台打造的一站式访客管理系统。员工发起预约，前台按状态分组管理访客签到/签退全流程，系统自动检测风险并生成统计报表，告别纸质登记和临时追问。

- 目标用户：企业前台人员、行政管理人员、普通员工
- 核心价值：规范访客流程、降低安全风险、提升接待效率、数据可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 前台人员 | 默认角色 | 签到/签退管理、访客牌分配、物品登记、查看风险提醒、查看统计 |
| 普通员工 | 选择姓名进入 | 发起访客预约、确认/拒绝接待、查看自己的预约记录 |
| 管理层 | 切换角色进入 | 全部权限 + 统计分析导出 |

### 2.2 功能模块

1. **前台首页**：今日访客分组看板（待到访/已签到/已离开/爽约）、风险提醒横幅、快速操作入口
2. **预约登记**：访客信息录入、预约创建、预约列表查看
3. **签到签退**：访客签到生成牌号、签退标记牌号归还、实时状态更新
4. **物品登记**：快递/设备携入携出记录、关联访客
5. **风险提醒**：无接待人确认、会议室冲突、访客证未归还等风险自动检测
6. **统计报表**：每日访客量趋势、部门接待排行、爽约率、超时停留分析

## 3. 核心流程

**访客预约全流程**：员工发起预约 → 系统检测风险（会议室冲突/无接待人确认）→ 前台收到待到访通知 → 访客到达前台签到 → 生成访客牌号 → 访客进入办公区 → 访客签退 → 标记访客牌归还 → 记录完成。若访客未按约定到达则标记爽约，若超时未签退则触发超时提醒。

```mermaid
flowchart TD
    "员工发起预约" --> "系统风险检测"
    "系统风险检测" --> "风险提醒（如有）"
    "系统风险检测" --> "预约创建成功"
    "预约创建成功" --> "前台：待到访列表"
    "前台：待到访列表" --> "访客到达签到"
    "访客到达签到" --> "生成访客牌号"
    "生成访客牌号" --> "已签到状态"
    "已签到状态" --> "访客签退"
    "访客签退" --> "标记牌号归还"
    "标记牌号归还" --> "已离开状态"
    "前台：待到访列表" --> "超时未到"
    "超时未到" --> "标记爽约"
```

**物品携入携出流程**：访客携带物品进入 → 前台登记携入信息 → 访客离开时核对 → 登记携出信息 → 确认无遗漏。

```mermaid
flowchart TD
    "访客携带物品进入" --> "前台登记携入"
    "前台登记携入" --> "记录物品信息"
    "访客签退时" --> "核对携入物品"
    "核对携入物品" --> "登记携出"
    "登记携出" --> "确认无遗漏"
    "确认无遗漏" --> "完成签退"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色 (#0F766E) 搭配暖橙强调色 (#F97316)，传达专业可靠与活力
- **辅助色**：石板灰 (#334155) 文字色，浅灰 (#F1F5F9) 背景色
- **按钮风格**：圆角 (rounded-lg)，主按钮实色填充，次按钮描边，危险按钮红色系
- **字体**：标题使用 DM Sans (Bold/Semibold)，正文使用 DM Sans (Regular/Medium)
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式布局，顶部统计卡片横向排列
- **图标**：Lucide React 图标库，线条风格，与整体简洁专业风格一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 前台首页 | 今日概览卡片 | 4张统计卡片横排，图标+数字+标签，颜色区分状态 |
| 前台首页 | 访客分组列表 | Tab切换4个状态组，卡片列表，每张含姓名/公司/时间/操作按钮 |
| 前台首页 | 风险提醒横幅 | 顶部固定横幅，红/橙色警告图标+文字+处理按钮 |
| 预约登记 | 预约表单 | 两列表单布局，输入框/下拉选择/时间选择器/文本域 |
| 预约登记 | 预约列表 | 表格布局，支持搜索和状态筛选，行操作按钮 |
| 签到签退 | 签到面板 | 访客搜索框 + 访客卡列表，签到按钮触发生成牌号弹窗 |
| 签到签退 | 访客牌号弹窗 | 居中弹窗显示牌号，打印按钮，确认按钮 |
| 物品登记 | 物品记录表 | 表单+表格组合，表单在上方，历史记录在下方 |
| 风险提醒 | 风险列表 | 左侧风险分类过滤，右侧风险卡片列表，含严重程度标签 |
| 统计报表 | 图表区域 | Chart.js 折线图/柱状图/饼图，时间范围选择器 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 统计卡片在小屏幕下从4列变2列
- 表格在移动端横向滚动
- 导航栏在移动端收缩为汉堡菜单

### 4.4 设计差异化

- 前台首页概览卡片带微妙的渐变背景和悬浮阴影
- 访客签到时牌号生成有数字翻转动画效果
- 风险提醒条目左侧带颜色条指示严重程度
- 统计图表区域使用渐变填充而非纯色
