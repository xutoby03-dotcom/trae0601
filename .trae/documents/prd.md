## 1. 产品概述

社团活动报名看板——面向学生社团和兴趣小组的活动组织工具，解决活动发布、报名管理、候补自动补位、签到统计等全流程痛点，让社团管理者轻松运营、成员便捷参与。

- 目标用户：大学/社区社团管理员及成员
- 核心价值：看板式活动可视化管理、候补自动补位、一键导出名单与费用汇总

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 预设账号 | 创建/编辑/删除活动、查看签到名单、导出数据、标记签到 |
| 普通用户 | 自由访问 | 浏览看板、报名/取消报名、查看活动详情 |

### 2.2 功能模块

1. **首页看板**：四列看板（未开始、报名中、已满员、已结束），活动卡片展示剩余名额与倒计时
2. **活动详情页**：报名表单、候补队列、签到名单、报名统计、费用汇总、导出名单按钮
3. **创建/编辑活动页**：填写标题、地点、时间、人数上限、费用、要带的东西、活动海报
4. **历史活动页**：出勤率统计、最受欢迎活动类型分析

|----------|----------|----------|

## 3. 核心流程

**管理员创建活动流程**：管理员登录 → 点击新建活动 → 填写活动信息 → 提交 → 活动自动归入"未开始"或"报名中"列

**用户报名流程**：用户浏览看板 → 点击活动卡片 → 查看详情 → 填写报名信息 → 提交 → 若有空位则报名成功，否则进入候补队列

**候补补位流程**：已报名用户取消 → 系统检测候补队列 → 自动将候补第一位补入正式名单 → 通知补位成功

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖橙 #F97316 作为活力色 + 深灰 #18181B 作为底色（暗色主题，年轻社团感）
- **辅色**：青绿 #06B6D4 用于状态提示，玫红 #EC4899 用于候补/紧急
- **按钮风格**：圆角微凸（rounded-xl + shadow），主按钮用渐变
- **字体**：标题用 Outfit（几何感），正文用 Noto Sans SC（中文友好）
- **布局风格**：四列看板横向滚动，卡片式布局，顶部导航
- **图标风格**：lucide-react 线性图标，与暗色主题搭配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页看板 | 顶部导航 | Logo + 新建活动按钮 + 历史活动入口，暗色背景 |
| 首页看板 | 看板列区 | 四列等宽，列头带状态标签和数量徽章，横向可滚动 |
| 首页看板 | 活动卡片 | 圆角卡片，海报缩略图 + 标题 + 标签（费用/地点）+ 剩余名额进度条 + 倒计时数字 |
| 活动详情页 | 活动信息区 | 大海报 + 渐变遮罩 + 信息网格 |
| 活动详情页 | 报名表单 | 模态框/侧面板，带朋友数量选择器 |
| 活动详情页 | 候补队列 | 折叠面板，候补人员列表带序号 |
| 活动详情页 | 统计区 | 数据卡片组（报名数/候补数/费用汇总）+ 导出按钮 |
| 创建活动页 | 表单 | 分步表单，海报上传拖拽区，时间选择器 |
| 历史活动页 | 统计面板 | 柱状图展示活动类型参与人数，环形图展示出勤率 |

### 4.3 响应式设计

- 桌面端优先：四列看板并排展示
- 平板端：两列看板，可横向滚动
- 移动端：单列纵向堆叠，底部导航
