## 1. 产品概述

LaTeX公式编辑器——类似Mathpix/CodeCogs的网页加强版，面向学生、教师、科研人员和工程师，提供所见即所得的LaTeX公式编写、管理和导出体验。三栏布局实时编辑预览，丰富的符号面板和模板预设，支持手写识别和图片识别，公式库管理与多项目IndexedDB持久化存储，还提供类Overleaf极简文档模式。

- 目标用户：需要频繁编写数学公式的学术/工程用户
- 核心价值：一站式LaTeX公式解决方案，从输入到输出全流程覆盖

## 2. 核心功能

### 2.1 用户角色
无角色区分，单用户本地应用。

### 2.2 功能模块
1. **编辑器主页**：三栏布局——LaTeX代码编辑器、实时预览区、符号面板
2. **模板预设面板**：典型公式一键插入，光标定位到首个占位符
3. **手写识别面板**：手写画板，识别为LaTeX
4. **图片识别面板**：上传图片，识别公式为LaTeX
5. **公式管理页**：公式片段库，保存/命名/分类/导入导出
6. **文档模式页**：类Overleaf极简版，混合文本与公式写作
7. **设置面板**：渲染尺寸/字体/颜色/背景、主题切换、导出选项

## 3. 核心流程

1. **公式编辑流程**：用户在左侧编辑器输入LaTeX → 200ms防抖后KaTeX渲染中间预览 → 点击符号面板符号插入到光标处 → 选择模板一键插入 → Tab键跳转占位符 → 调整渲染设置 → 导出为PNG/SVG/PDF/MathML
2. **识别流程**：用户手写/上传图片 → 前端mock识别 → 返回LaTeX填入编辑器 → 用户修正 → 渲染预览
3. **公式管理流程**：编辑完成 → 保存公式（命名+分类）→ 公式库列表浏览 → 搜索筛选 → 加载到编辑器 → 批量导入导出
4. **文档模式流程**：切换到文档模式 → 混合编写文本与公式 → 实时预览 → 导出PDF

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深墨蓝(#1a1b2e)为深色主题基底，象牙白(#f8f7f4)为浅色主题基底
- **强调色**：琥珀橙(#e8a838)作为交互强调色，薄荷绿(#4ecdc4)作为辅助强调
- **按钮风格**：圆角8px，微妙阴影，hover时轻微上浮效果
- **字体**：编辑器使用JetBrains Mono，UI使用Source Sans 3，数学公式由KaTeX渲染
- **布局风格**：三栏等宽或可拖拽调整比例，顶栏导航+工具栏
- **图标风格**：Lucide线性图标，2px描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 编辑器主页 | LaTeX编辑器 | CodeMirror暗色主题编辑器，行号，语法高亮，底部状态栏 |
| 编辑器主页 | 实时预览 | 居中渲染区，白色/深色背景可切换，缩放控制 |
| 编辑器主页 | 符号面板 | 顶部Tab切换，网格布局符号按钮，hover预览效果 |
| 编辑器主页 | 工具栏 | 导出下拉菜单、设置按钮、主题切换、模式切换 |
| 公式管理页 | 公式列表 | 卡片网格布局，缩略图+名称+分类标签 |
| 文档模式页 | 双栏布局 | 左侧编辑器+右侧实时PDF预览 |

### 4.3 响应式设计
桌面优先设计，三栏布局在窄屏下可折叠为Tab切换模式。

### 4.4 动效
- 符号面板切换Tab：滑动过渡
- 公式渲染：淡入效果
- 主题切换：全局颜色过渡动画
- 按钮交互：hover缩放+阴影加深
