## 1. 产品概述

前台快递收发管理台——解决前台包裹登记混乱、取件无记录、冷链易碎件难追踪的痛点，面向企业前台行政人员与全体员工。
- 告别便利贴时代，实现包裹全生命周期数字化管理：录入 → 分组展示 → 手机尾号核验签收 → 超时提醒 → 统计分析
- 降低丢件率、提升取件效率、冷链/易碎件特殊标记防损

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 前台管理员 | 后台预设账号 | 录入包裹、编辑/删除、查看统计、处理异常 |
| 普通员工 | 手机号尾号核验 | 查看待取包裹、签收取件 |

### 2.2 功能模块

1. **包裹首页**：按新到、待领取、已领取、异常包裹四组展示，支持搜索筛选、超时提醒高亮、冷藏件醒目标记
2. **包裹录入页**：表单录入收件人、部门、快递公司、取件码、货架位置、是否易碎、是否冷藏、照片上传
3. **取件签收页**：核验手机号尾号 → 确认签收，支持批量签收
4. **统计页**：每日到件量趋势、部门包裹排行、超时未取次数统计

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

| 包裹首页 | 搜索与筛选 | 支持按收件人、取件码、快递公司、部门筛选，冷藏/易碎/超时快捷筛选标签 |

## 3. 核心流程

**包裹录入流程**：前台收到快递 → 填写收件人和快递信息 → 标记易碎/冷藏 → 拍照存档 → 提交入库 → 包裹出现在"新到"列表

**取件签收流程**：员工到前台 → 搜索或扫码找到包裹 → 输入手机号后4位核验 → 确认签收 → 包裹移入"已领取"

**超时提醒流程**：系统定时检查 → 普通包裹超2天未取标记超时 → 冷藏件超4小时未取标记超时 → 首页横幅提醒 → 异常包裹列表高亮

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：暖灰 #F5F0EB 底色 + 靛蓝 #2D3A8C 强调色 + 珊瑚红 #E85D4A 警告色 + 冰蓝 #4FC3F7 冷藏标识
- 按钮风格：圆角 8px，轻投影，主操作按钮靛蓝填充，次要操作描边
- 字体：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- 布局风格：左侧导航栏 + 右侧内容区，卡片式布局
- 图标风格：线性图标，2px 描边，与文字等高对齐

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 包裹首页 | 状态分组 | 顶部四个 Tab 切换，每个 Tab 带数量角标；卡片列表每行一张，左侧状态色条，右侧冷藏冰晶图标/易碎气泡/超时脉冲动画 |
| 包裹首页 | 搜索筛选 | 顶部搜索框 + 标签式快捷筛选，搜索框圆角带放大镜图标 |
| 包裹首页 | 超时横幅 | 顶部固定横幅，珊瑚红背景，白色文字，脉冲动画吸引注意 |
| 包裹录入页 | 基础表单 | 上方为表单区，输入框带标签，下拉选择带搜索，开关式切换易碎/冷藏 |
| 包裹录入页 | 照片上传 | 虚线框上传区，点击上传，缩略图网格展示，支持删除 |
| 取件签收页 | 尾号核验 | 大号4位输入框，类似验证码输入，逐格填写，自动聚焦下一格 |
| 取件签收页 | 包裹确认 | 卡片式包裹详情，底部绿色签收按钮，签收成功弹出勾号动画 |
| 统计页 | 趋势图表 | 卡片内嵌折线图，靛蓝线条，浅色填充区域 |
| 统计页 | 排行榜 | 横向柱状图，渐变填充，部门名称左侧标注 |

### 4.3 响应式

- 桌面优先设计，1920px 为主视口
- 平板适配：左侧导航栏折叠为底部 Tab，卡片单列排列
- 手机适配：隐藏侧栏，顶部汉堡菜单，卡片全宽
