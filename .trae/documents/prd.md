## 1. 产品概述

课程作业截止雷达是一款面向学生群体的作业deadline管理工具，通过雷达可视化让用户一眼看清哪些作业即将到期，有效避免拖延和遗忘。目标用户为在校大学生，核心价值在于将繁杂的作业截止信息转化为直觉化的视觉信号，让时间管理变得简单高效。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学生 | 无需注册，本地使用 | 所有功能 |

### 2.2 功能模块

1. **雷达首页**：雷达盘可视化、紧急任务卡片列表、红色预警提醒
2. **课程管理页**：课程增删改、老师/上课时间/学分/颜色设置
3. **作业管理页**：作业增删改、步骤拆分、进度追踪、提交方式/附件链接
4. **周视图页**：按周查看每天要交的作业
5. **统计页**：课程拖延分析、月度完成统计

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 雷达首页 | 雷达盘 | 同心圆表示时间紧迫程度，越靠近中心越紧急，每个作业是雷达上的一个点，颜色对应课程 |
| 雷达首页 | 紧急任务卡片 | 按紧急程度自动排序的任务卡片列表，显示标题、课程、截止时间、进度条 |
| 雷达首页 | 红色预警 | 快截止但进度低的作业标红提醒（距离截止<24h且进度<50%，或距离截止<48h且进度<30%） |
| 课程管理 | 课程列表 | 展示所有课程，显示颜色标识、老师、上课时间、学分 |
| 课程管理 | 课程表单 | 添加/编辑课程：课程名、老师、上课时间（星期+节次）、学分、主题色 |
| 作业管理 | 作业列表 | 按课程/紧急程度筛选的作业列表 |
| 作业管理 | 作业表单 | 添加/编辑作业：标题、所属课程、截止时间、预计耗时、提交方式、附件链接、完成进度 |
| 作业管理 | 步骤拆分 | 大作业可拆成多个子步骤（如查资料、写初稿、修改、提交），每步可单独打勾完成 |
| 周视图 | 周日历 | 按周一到周日展示，每天显示当天要交的作业 |
| 周视图 | 周切换 | 上周/下周切换，快速跳转当前周 |
| 统计页 | 课程拖延排名 | 哪门课最容易拖延（按平均完成进度与剩余时间比值计算） |
| 统计页 | 月度完成统计 | 本月已完成/未完成/进行中的任务数量，完成率环形图 |
| 统计页 | 时间分布 | 各课程作业耗时分布 |

## 3. 核心流程

用户打开应用后，首先看到雷达首页，直观了解所有作业的紧急程度。用户可以：
1. 在课程管理页添加课程信息
2. 在作业管理页添加作业并拆分步骤
3. 回到雷达首页查看紧急情况
4. 切换到周视图查看本周安排
5. 在统计页查看学习习惯分析

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色背景（#0a0e1a）+ 霓虹风格点缀色（青色#00f5d4、品红#f72585、琥珀#fca311）
- **辅助色**：课程自定义颜色，红#ff4757用于紧急预警
- **按钮风格**：圆角微发光按钮，hover时增强发光效果
- **字体**：标题用 Orbitron（科技感），正文用 Noto Sans SC
- **布局风格**：左侧导航栏 + 右侧内容区，雷达盘居中展示
- **图标风格**：Lucide线性图标，配合霓虹色调

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 雷达首页 | 雷达盘 | 深色背景、同心圆网格线（半透明青色）、脉冲动画、作业点（课程颜色+大小表示紧急度）、扫描线旋转动画 |
| 雷达首页 | 任务卡片 | 玻璃态卡片、左侧课程颜色条、进度条、红色边框闪烁预警 |
| 课程管理 | 课程列表 | 卡片网格布局、课程颜色色块、编辑/删除按钮 |
| 课程管理 | 课程表单 | 弹窗模态框、颜色选择器、时间选择器 |
| 作业管理 | 作业列表 | 筛选标签栏、作业卡片、进度百分比 |
| 作业管理 | 步骤拆分 | 内嵌折叠区域、复选框步骤列表、进度自动计算 |
| 周视图 | 周日历 | 7列网格、日期头部、作业标签（课程颜色）、当周高亮 |
| 统计页 | 拖延排名 | 横向柱状图、红黄绿渐变色 |
| 统计页 | 月度统计 | 环形进度图、数字统计卡片 |

### 4.3 响应式设计

- 桌面优先设计，导航栏在左侧
- 平板端导航栏折叠为顶部
- 移动端底部Tab导航，内容区自适应

### 4.4 动效设计

- 雷达扫描线：持续旋转动画（4s一圈）
- 作业点：脉冲呼吸动画，紧急的频率更快
- 预警卡片：边框红色闪烁
- 页面切换：淡入淡出过渡
- 步骤完成：打勾动画+进度条平滑更新
