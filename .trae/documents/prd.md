## 1. 产品概述

电影台词截图整理器 —— 为那些看到好台词就想存下来的人打造。用户可以上传电影截图，添加电影名、角色、台词文字、时间点、情绪标签和个人感想，以胶片墙的形式按电影分组展示，支持筛选、编辑和分享。

- 目标用户：电影爱好者、台词收藏者、文艺青年
- 核心价值：让每一句打动人心的台词都有归处，从零散截图变成有组织的私人台词博物馆

## 2. 核心功能

### 2.1 用户角色
无角色区分，单用户本地应用。

### 2.2 功能模块
1. **胶片墙首页**：按电影分组的胶片墙展示，点击进入某部电影查看所有台词卡
2. **台词上传页**：上传截图并添加元数据（电影名、角色、台词、时间点、情绪标签、感想）
3. **台词详情页**：裁剪台词区域、调整亮度、添加字幕框、生成分享卡片
4. **摘录模式**：纯文字输入生成精美台词卡
5. **筛选功能**：按台词关键词、情绪、角色、年份筛选
6. **统计页面**：收藏情绪分布、最热电影、最热角色等数据可视化

## 3. 核心流程

### 3.1 上传台词截图流程
用户点击"添加台词" → 选择上传截图或进入摘录模式 → 上传截图后填写电影名、角色、台词文字、时间点、情绪标签、感想 → 保存 → 返回胶片墙首页，新截图出现在对应电影分组中

### 3.2 编辑与分享流程
用户点击某张台词卡 → 进入详情页 → 可裁剪截图区域、调整亮度、添加字幕框 → 满意后点击"生成分享卡片" → 系统合成分享图 → 用户下载保存

### 3.3 筛选流程
用户在胶片墙首页点击筛选 → 选择情绪标签/输入年份/搜索角色/输入关键词 → 实时过滤展示匹配结果 → 清除筛选恢复全部展示

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深色电影院风格，暗灰/炭黑背景（#1a1a2e），琥珀色/金色点缀（#e2b714）模拟影院灯光
- **辅助色**：暗红色（#c0392b）用于情绪热烈标签，冷蓝色（#2980b9）用于忧郁标签
- **按钮风格**：圆角胶囊按钮，琥珀色主按钮，深色次按钮带细边框
- **字体**：标题使用 Playfair Display（衬线体，复古影院感），正文使用 DM Sans（现代简洁），中文回退到 Noto Serif SC / Noto Sans SC
- **布局风格**：胶片齿孔装饰条、卡片式台词展示、深色沉浸式背景
- **图标风格**：Lucide 线性图标，与胶片/电影主题呼应

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |

### 4.3 响应式设计
桌面优先设计，胶片墙在大屏上多列横向胶片条展示，平板上减少列数，移动端改为单列纵向滚动。编辑器在移动端改为上下布局。

### 4.4 设计灵感
复古电影院 —— 暗场氛围、胶片质感、金色灯光、字幕框元素。整体像在一家老式影院翻看自己的台词收藏本。
