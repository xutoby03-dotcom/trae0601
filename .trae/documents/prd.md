## 1. 产品概述

烘烤批次看板是一款面向面包店、甜品店后厨的实时生产管理工具。解决多批次、多烤箱并行烘烤时的调度混乱、烤过头、记录缺失等问题，通过可视化看板+倒计时提醒+数据统计帮助烘焙师高效把控出品节奏。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 烘焙师 | 无需注册（本地单机应用） | 批次管理、烤箱调度、出炉记录、统计查看 |

### 2.2 功能模块

1. **批次看板主页**：批次卡片瀑布流、烤箱占用总览、统计数据速览
2. **新建批次面板**：产品信息录入、入炉拍照、烤箱/层位选择
3. **批次倒计时卡片**：实时倒计时、临近变色提醒、一键出炉
4. **烤箱占用可视化**：多层烤箱横向布局、层位占用状态实时显示
5. **出炉记录面板**：实际时长、成色评分、报损数量、出炉拍照
6. **统计报表**：报损排行、平均超时、烤箱利用率

## 3. 核心流程

```mermaid
flowchart LR
    A["烘焙师点击新建批次"] --> B["填写产品名/数量/时长/温度"]
    B --> C["选择可用烤箱及层位"]
    C --> D["拍摄入炉照片"]
    D --> E["批次创建，开始倒计时"]
    E --> F["卡片颜色随剩余时间变化"]
    F --> G{"倒计时结束"}
    G --> H["点击出炉按钮"]
    H --> I["记录实际时长/成色/报损"]
    I --> J["拍摄出炉照片"]
    J --> K["批次完成，释放层位"]
    K --> L["数据进入统计报表"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖铜色 `#D2691E`（面包烘焙感）+ 深棕 `#3E2723` + 奶油米 `#FFF8E7`
- **辅助色**：橙色 `#FF8C42`（临近提醒）、红色 `#E53935`（超时警告）、绿色 `#43A047`（正常）
- **按钮风格**：圆润胶囊形，4px 圆角，轻微阴影，悬停有缩放和发光
- **字体**：标题用 `Playfair Display` 衬线体（精致感），正文用 `Noto Sans SC` 无衬线体（可读性）
- **布局风格**：三栏式卡片布局，左侧烤箱状态，中间批次看板，右侧统计
- **图标风格**：LineAwesome 线性图标，烘焙相关 emoji 辅助（🥐、🍞、🔥、⏱️）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 批次看板主页 | 顶部导航 | 品牌logo、当前时间、日期切换、统计面板切换按钮 |
| 批次看板主页 | 烤箱状态区 | 每台烤箱为竖向卡片，显示层位条，已占用层位标注产品名和剩余时间 |
| 批次看板主页 | 批次卡片流 | 瀑布流卡片，根据剩余时间显示不同颜色边框和背景 |
| 批次看板主页 | 统计概览条 | 4个数字卡片展示关键指标 |
| 新建批次面板 | 表单弹窗 | 毛玻璃背景，大输入框，圆角，分组标题 |
| 批次倒计时卡片 | 卡片主体 | 倒计时大字居中，产品名上方，烤箱信息和层位在角标 |
| 出炉记录面板 | 表单弹窗 | 自动填充实际时长，星级评分组件，报损数量加减器 |
| 统计报表 | 图表区 | 柱状图+折线图，暖色调配色 |

### 4.3 响应式

- Desktop-first 设计，主视区 ≥ 1440px
- 平板：烤箱区折叠为可切换的 Tab，批次卡片单列
- 手机：三栏合并为纵向滚动，烤箱和统计可折叠

## 5. 数据持久化

- 使用 LocalStorage 存储所有批次和烤箱数据
- 支持导出 JSON 备份
- 每日自动归档历史批次
