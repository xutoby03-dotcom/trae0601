## 1. 产品概述

社区噪音投诉记录平台——让噪音投诉从群聊争吵变成有序记录与追踪。居民可记录楼上装修、夜间唱歌、广场音响等各类噪音事件，邻居可附议避免重复，物业可追踪处理进度，让问题真正被看见和解决。

- 目标用户：社区居民（投诉与附议）、物业管理人员（处理与跟进）
- 核心价值：将零散的噪音投诉结构化管理，提供温和沟通话术减少冲突，通过数据统计推动长效治理

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 居民 | 手机号注册 | 提交投诉、附议、查看统计 |
| 物业 | 管理员分配账号 | 居民全部权限 + 记录处理动作、更新状态 |

### 2.2 功能模块

1. **首页**：按状态分组的投诉列表（正在发生/待沟通/已解决/反复出现）
2. **新增投诉页**：填写噪音事件详情
3. **投诉详情页**：查看详情、附议、物业处理记录
4. **沟通话术页**：按场景提供温和提醒话术
5. **统计页**：时段分布、类型占比、复发分析

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 状态分组标签栏 | 切换"正在发生/待沟通/已解决/反复出现"分组 |
| 首页 | 投诉卡片列表 | 每条显示类型图标、位置、时间、附议数、状态标签 |
| 首页 | 新增投诉入口 | 右下角悬浮按钮 |
| 新增投诉页 | 基本信息表单 | 时间选择、位置输入（楼栋/楼层/房号）、噪音类型下拉（装修/唱歌/音响/宠物/其他） |
| 新增投诉页 | 补充信息表单 | 持续时长、分贝估计（安静<40/较吵40-60/很吵60-80/震耳>80）、是否影响休息 |
| 新增投诉页 | 附件与备注 | 照片上传、录音上传、文字备注 |
| 投诉详情页 | 投诉信息展示 | 完整展示投诉所有字段 |
| 投诉详情页 | 附议区域 | 显示附议人数，居民可一键附议 |
| 投诉详情页 | 处理记录时间线 | 物业记录的处理动作：已上门/已联系/已报警/约定整改时间 |
| 投诉详情页 | 状态更新 | 物业可更新投诉状态 |
| 沟通话术页 | 场景分类 | 装修噪音/夜间噪音/广场噪音/宠物噪音 |
| 沟通话术页 | 话术卡片 | 每个场景3-5条温和话术，一键复制 |
| 统计页 | 时段分析 | 24小时噪音投诉热力分布 |
| 统计页 | 类型分析 | 各类噪音占比饼图 |
| 统计页 | 位置复发分析 | 同一位置投诉次数排名 |

## 3. 核心流程

居民发现噪音 → 填写投诉表单（时间/位置/类型/时长/分贝/附件）→ 提交后出现在首页"正在发生"分组 → 其他邻居看到后可附议 → 物业查看投诉详情 → 记录处理动作（已上门/已联系/已报警/约定整改）→ 更新状态为"待沟通"或"已解决" → 同一位置重复投诉标记为"反复出现"

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青色 (#0D9488) 代表安静与秩序，辅助色琥珀橙 (#F59E0B) 代表警示与关注
- 按钮风格：圆角卡片式，轻微阴影，状态色彩分明
- 字体：思源黑体/Noto Sans SC 为正文，标题用粗体大号
- 布局：卡片式列表，顶部标签切换，底部导航栏
- 图标风格：线性图标（lucide-react），配合状态色彩

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 状态分组标签栏 | 横向滚动标签，选中态底部色条，平滑切换动画 |
| 首页 | 投诉卡片列表 | 卡片左侧类型色条，右侧箭头，附议数气泡，状态角标 |
| 首页 | 新增投诉按钮 | 右下角悬浮圆形按钮，主色调，点击缩放动画 |
| 新增投诉页 | 表单区域 | 分段卡片式表单，输入框聚焦时色条高亮 |
| 新增投诉页 | 分贝选择器 | 四档滑块选择，每档不同颜色（绿/黄/橙/红） |
| 投诉详情页 | 时间线 | 纵向时间线，节点圆点+连接线，处理动作卡片 |
| 投诉详情页 | 附议按钮 | 底部固定操作栏，附议计数动画 |
| 沟通话术页 | 话术卡片 | 圆角卡片+场景图标，右下角复制按钮 |
| 统计页 | 时段热力图 | 横向24格热力条，颜色深浅代表投诉频次 |
| 统计页 | 类型饼图 | 环形图+中心总数，悬停高亮 |
| 统计页 | 复发排名 | 横向柱状图，渐变色柱体 |

### 4.3 响应式设计

- 桌面优先设计，最大宽度 1024px 居中
- 移动端自适应：卡片全宽，标签栏吸顶，底部操作栏固定
- 触控优化：按钮最小 44px 触控区域，附议按钮放大
