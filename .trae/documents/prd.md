## 1. 产品概述

民宿入住清洁检查系统——解决房东与保洁之间仅靠几张照片交接的低效问题。通过结构化检查单、清洁前后照片上传、备品缺漏记录和房东复核返工机制，确保每套房源退房后达到入住标准。

- 目标用户：民宿房东、保洁人员
- 核心价值：用标准化流程替代碎片化照片交接，降低返工率和客诉率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 房东 | 默认身份 | 管理房源、分配保洁、复核检查单、查看统计 |
| 保洁 | 被分配任务 | 执行检查单、上传照片、记录备品缺漏 |

### 2.2 功能模块

1. **首页看板**：按状态分组展示今日退房、待清洁、待复核、可入住房源
2. **房源管理**：添加/编辑房源信息（房间数、床数、备品标准、保洁负责人、入住时间）
3. **检查单**：退房后自动生成，逐项确认（床品、浴室、厨房、地面、垃圾、冰箱、门锁、遥控器）
4. **清洁执行**：保洁上传清洁前后照片，记录缺少的纸巾/洗发水/矿泉水等备品
5. **房东复核**：标记返工项和扣费原因，确认通过后房源变为可入住
6. **统计面板**：保洁平均耗时、返工最多的项目、备品消耗趋势、投诉最多的房源

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 状态看板 | 四列看板：今日退房、待清洁、待复核、可入住，每列显示房源卡片 |
| 首页 | 快捷操作 | 新建检查单、添加房源入口 |
| 房源管理 | 房源列表 | 展示所有房源，支持搜索和筛选 |
| 房源管理 | 房源表单 | 添加/编辑房源：名称、地址、房间数、床数、备品标准、保洁负责人、入住时间 |
| 检查单详情 | 检查项清单 | 八大类逐项确认，每项可勾选合格/不合格 |
| 检查单详情 | 照片上传 | 保洁上传清洁前、清洁后照片 |
| 检查单详情 | 备品记录 | 记录缺少的纸巾、洗发水、矿泉水等，数量可填 |
| 检查单详情 | 计时器 | 自动记录保洁开始和完成时间 |
| 复核页 | 返工标记 | 房东对不合格项标记返工，填写扣费原因 |
| 复核页 | 通过确认 | 全部合格后确认房源可入住 |
| 统计页 | 保洁效率 | 平均耗时、最短/最长耗时 |
| 统计页 | 返工分析 | 返工最多的项目排行 |
| 统计页 | 备品消耗 | 各类备品消耗数量和趋势 |
| 统计页 | 投诉排名 | 被投诉最多的房源排名 |

## 3. 核心流程

退房后系统自动生成检查单 → 保洁收到任务通知 → 保洁逐项检查并上传清洁前后照片 → 记录缺少备品 → 保洁提交完成 → 房东收到复核通知 → 房东逐项复核，标记返工项和扣费原因 → 返工项返回保洁重做 → 全部通过后房源变为可入住状态

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：暖棕色 (#8B6F47) 传达温馨民宿感，辅色：柔绿 (#5B8C5A) 代表清洁/通过
- 警告色：珊瑚红 (#E07A5F) 用于返工/不合格标记
- 按钮风格：圆角 8px，微阴影，hover 有轻微抬升效果
- 字体：思源宋体风格标题 + 无衬线正文，标题粗体大号，正文 14px
- 布局：左侧导航 + 右侧内容区，卡片式布局
- 图标：使用 lucide-react 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | 状态看板 | 四列拖拽卡片布局，每列有状态色条，卡片显示房源名、保洁人、时间 |
| 首页 | 快捷操作 | 右上角悬浮操作按钮，点击展开菜单 |
| 房源管理 | 房源列表 | 网格卡片，每个卡片展示房源缩略信息 |
| 房源管理 | 房源表单 | 侧滑抽屉式表单，分步填写 |
| 检查单详情 | 检查项清单 | 分组折叠面板，每组一个图标，勾选有动画反馈 |
| 检查单详情 | 照片上传 | 虚线框拖拽上传区域，缩略图网格展示 |
| 检查单详情 | 备品记录 | 表格行内编辑，加减按钮调数量 |
| 检查单详情 | 计时器 | 顶部悬浮计时条，开始/暂停/完成按钮 |
| 复核页 | 返工标记 | 不合格项高亮红色边框，点击展开扣费原因输入 |
| 统计页 | 各统计模块 | 图表卡片，柱状图+环形图，数据筛选器 |

### 4.3 响应式设计

- 桌面优先设计，最低支持 1024px 宽度
- 平板：看板从四列变为两列
- 移动端：看板变为单列 tab 切换
