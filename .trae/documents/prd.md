## 1. 产品概述

周末亲子任务抽签——解决"周末不知道带孩子干嘛"的痛点。家长往任务池里添加活动，系统随机抽取，配合天气、时长、预算等条件筛选，让每个周末都有新鲜玩法。完成后孩子打星、家长写感想，还能回顾这个月一起做了什么。

- 目标用户：有 3-12 岁孩子的家庭
- 核心价值：把"选活动"变成趣味抽签，降低决策疲劳，增加亲子互动仪式感

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 家长 | 无需注册，本地使用 | 管理任务池、筛选、查看统计、写感想 |
| 孩子 | 无需注册，本地使用 | 抽签、打星星评级 |

### 2.2 功能模块
1. **抽签首页**：抽签盒子动画、随机抽任务、换一个（记录换掉原因）、条件快捷筛选
2. **任务池**：添加/编辑/删除任务、任务卡片列表、条件筛选面板
3. **任务详情**：步骤清单（可勾选）、完成照片上传、打星星、家长感想
4. **统计页**：月度完成日历、活动类型分布、完成趋势

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 抽签首页 | 抽签盒子 | 点击盒子触发摇晃动画，随机抽取一个任务，展示任务卡片 |
| 抽签首页 | 换一个 | 不想做可以换，弹出换掉原因选择（太累/没材料/不想出门/其他），记录后重新抽取 |
| 抽签首页 | 快捷筛选 | 天气（晴天/下雨）、时长（<30分钟/30-60分钟/1小时+）、预算（免费/50以内/不限）、体力（轻松/适中/旺盛）、场景（室内/室外） |
| 任务池 | 任务列表 | 卡片式展示所有任务，显示名称、年龄、时长、预算、场景标签 |
| 任务池 | 添加任务 | 表单填写：名称、适合年龄、预计时长、预算、室内/室外、准备物品、体力强度、步骤清单 |
| 任务池 | 筛选面板 | 与首页筛选条件一致，可组合筛选 |
| 任务详情 | 步骤清单 | 可勾选的步骤列表，实时标记进度 |
| 任务详情 | 完成照片 | 上传活动过程/成果照片，本地预览展示 |
| 任务详情 | 评分与感想 | 孩子1-5星评级（星星动画），家长文字感想 |
| 统计页 | 月度日历 | 日历视图标注完成日期，点击查看当天活动 |
| 统计页 | 数据概览 | 本月完成数、室内外比例、总时长、平均评分 |
| 统计页 | 活动列表 | 本月已完成活动按时间倒序排列 |

## 3. 核心流程

用户打开应用 → 首页看到抽签盒子 → 可先设置筛选条件（如"下雨天+不想花钱"）→ 点击抽签 → 盒子摇晃动画 → 随机抽出一个任务 → 查看/换一个（记录原因）→ 接受任务 → 进入任务详情 → 按步骤执行 → 上传照片 → 打星星+写感想 → 回到首页或查看统计

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：暖橙色 #FF6B35 + 奶油白 #FFF8F0，搭配薄荷绿 #4ECDC4 作为点缀
- **次色调**：柔粉 #FF8FAB、天蓝 #45B7D1、阳光黄 #F7DC6F
- **按钮风格**：圆角大按钮，3D 凸起效果，带有微妙阴影，按压时有下沉反馈
- **字体**：标题用圆润手写风格字体，正文用清晰友好的无衬线字体
- **布局风格**：卡片式布局，圆角卡片带柔和阴影，顶部标签导航
- **图标风格**：可爱手绘风 emoji 风格，圆滚滚的插画感
- **整体氛围**：温暖、童趣、手作感，像一本精心制作的亲子手账

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 抽签首页 | 抽签盒子 | 居中大号盲盒造型，橙色渐变底色+星星装饰，点击时摇晃弹跳动画，底部"摇一摇"按钮 |
| 抽签首页 | 快捷筛选 | 横向滚动标签条，选中的标签高亮填充色，未选中为描边态 |
| 抽签首页 | 结果卡片 | 从盒子中弹出动画，展示任务名称+标签+简介，底部"接受"+"换一个"两个按钮 |
| 任务池 | 任务卡片 | 圆角卡片，左侧彩色场景标签（室内蓝/室外绿），标题+3个关键属性图标行 |
| 任务池 | 添加按钮 | 右下角浮动圆形按钮，橙色+白色加号，点击展开表单模态框 |
| 任务详情 | 步骤清单 | 圆形序号+文字，勾选后变绿+删除线+弹跳动画 |
| 任务详情 | 星星评分 | 5颗大星星，点击后从左到右逐个亮起+放大弹跳效果 |
| 任务详情 | 照片墙 | 圆角方格网格，支持点击上传，照片带轻微旋转角度 |
| 统计页 | 月度日历 | 网格日历，完成日期显示小圆点（不同颜色代表不同场景），当前日期高亮 |
| 统计页 | 数据卡片 | 圆角统计卡片，大号数字+图标+标签文字 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度 1024px
- 平板适配：768px-1024px 卡片改为双列
- 手机适配：< 768px 单列布局，底部标签导航，大按钮便于触控

### 4.4 动效设计
- 抽签盒子摇晃：CSS keyframe 左右旋转 + 弹性缩放
- 卡片弹出：从中心放大 + 轻微上移，带弹性缓动
- 星星点亮：逐个延迟点亮 + scale 弹跳
- 步骤勾选：打勾 + 文字划线 + 背景色渐变
- 页面切换：淡入淡出 + 轻微上移
