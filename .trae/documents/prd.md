## 1. 产品概述

家庭净水器滤芯管家——帮助用户主动管理家中净水器滤芯的更换周期、记录水质变化、统计滤芯花费，避免"水变慢才想起换芯"的被动局面。面向所有使用家用净水器的家庭用户，通过可视化寿命提醒和水质趋势分析，让滤芯管理从被动变为主动。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 家庭用户 | 无需注册，本地使用 | 管理净水器、记录换芯、查看统计 |

### 2.2 功能模块

1. **首页仪表盘**：按滤芯类型分卡片展示，颜色状态提醒，快速总览
2. **净水器管理**：添加/编辑净水器及其滤芯配置
3. **换芯记录**：记录每次换芯详情，自动重置剩余寿命
4. **水质日志**：记录出水速度、TDS、异味反馈，趋势分析与异常预警
5. **统计中心**：年度花费、换芯频率、合并购买建议

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：清新水感科技风——以深青色（teal）为主色，搭配清澈的水蓝色，传达"净水"主题
- **主色**：深青色 #0D9488（teal-600），辅色：水蓝色 #06B6D4（cyan-500）
- **警告色**：橙色 #F59E0B（即将到期）、红色 #EF4444（已超期）
- **正常色**：翠绿 #10B981
- **按钮风格**：圆角 8px，微阴影，hover 时轻微上浮
- **字体**：标题使用 Outfit（几何感现代字体），正文使用 DM Sans
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式布局
- **图标**：使用 lucide-react 图标库，水滴、过滤、仪表等主题图标
- **动效**：卡片 hover 微浮起，数据变化时数字滚动，进度条动画填充

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 首页仪表盘 | 滤芯状态卡片 | 圆角卡片，顶部色条（绿/橙/红），环形进度条显示剩余寿命%，滤芯名称和剩余天数，点击进入详情 |
| 首页仪表盘 | 水质异常提醒 | 顶部横幅，脉冲动画背景，水滴警告图标，点击跳转水质日志 |
| 首页仪表盘 | 快捷操作 | 底部浮动按钮组，换芯/录水质/统计 |
| 净水器管理 | 净水器列表 | 卡片列表，品牌型号大字，安装日期小字，右上角编辑/删除 |
| 净水器管理 | 添加表单 | 模态对话框，表单字段带图标，品牌/型号/日期/购买链接 |
| 净水器管理 | 滤芯配置 | 可添加多行，每行选滤芯类型+输入寿命天数+购买链接 |
| 换芯记录 | 换芯表单 | 模态对话框，下拉选净水器和滤芯，日期选择器，金额输入 |
| 换芯记录 | 换芯历史 | 时间线样式，左侧日期，右侧滤芯类型标签+金额 |
| 水质日志 | 数据录入 | 紧凑表单，三列（速度/TDS/异味），快速提交 |
| 水质日志 | 趋势图表 | 双 Y 轴折线图，速度和 TDS 各一条线，异常点标红 |
| 统计中心 | 年度花费 | 大数字卡片+月度柱状图 |
| 统计中心 | 换芯频率 | 横向柱状图，按滤芯类型排名 |
| 统计中心 | 合并购买 | 列表卡片，30天内到期滤芯，一键复制清单 |

### 4.3 响应式设计

- 桌面优先设计，左侧导航栏在移动端变为底部标签栏
- 卡片网格在桌面端 3 列，平板 2 列，手机 1 列
- 图表在移动端可横向滚动查看
