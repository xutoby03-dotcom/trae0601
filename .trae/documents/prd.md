## 1. 产品概述

宠物寄养托付清单——帮助宠物主人在出差、旅行时，将猫咪或狗狗安心交给朋友或寄养店。通过结构化的交接单和每日打卡机制，确保照看人不遗漏任何细节，主人也能实时了解宠物状态。

- 解决问题：宠物寄养时信息传递不完整、照看人容易遗漏事项、主人无法了解宠物实际状况
- 目标用户：需要短期寄养宠物的城市养宠人群，以及代为照看的亲友或寄养店工作人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 宠物主人 | 创建宠物档案和寄养交接单 | 管理宠物档案、创建寄养单、留言提醒、查看统计 |
| 照看人 | 接收交接单并执行每日打卡 | 查看交接单、每日打卡、上传照片、记录异常 |

### 2.2 功能模块

1. **宠物档案页**：管理所有宠物信息，支持添加/编辑/查看
2. **寄养交接单页**：创建寄养任务，按喂食/清洁/外出/健康观察分块展示交接事项
3. **每日打卡页**：照看人每日记录吃饭、排便、精神状态和异常，上传照片
4. **留言板**：主人留言提醒，如"别让它上沙发"
5. **统计页**：寄养期间打卡完成率、异常出现时间线、用品消耗提醒

## 3. 核心流程

用户使用流程：宠物主人首先创建宠物档案，录入完整信息。当需要寄养时，创建一份寄养交接单，详细填写喂食、清洁、外出、健康观察等板块的注意事项。照看人收到交接单后，每天进行打卡记录，包括饮食、排便、精神状态和异常情况，并可上传照片。主人可随时留言提醒，统计页面实时展示寄养进度。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖棕色(#8B6F47)作为主色，搭配奶油白(#FFF8F0)背景，传达温暖可信赖的感觉
- **辅助色**：柔和绿色(#7BAE7F)用于完成状态，珊瑚橙(#E8845C)用于提醒和异常标记
- **按钮风格**：圆角柔和，带轻微阴影，悬浮时有微妙的上浮动画
- **字体**：标题使用有温度的衬线体，正文使用清爽的无衬线体
- **布局风格**：卡片式布局，交接单采用类似纸质表单的质感，带手写风格装饰
- **图标风格**：线条圆润的手绘风格图标，搭配温馨的宠物相关插画元素

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 宠物档案页 | 宠物列表 | 暖色卡片网格，每张卡片含宠物头像占位、名字标签、品种徽章，悬浮时卡片微微上浮 |
| 宠物档案页 | 添加表单 | 分步表单，带进度指示器，输入框圆角带暖色聚焦边框 |
| 寄养交接单页 | 交接单主体 | 模拟纸质交接单质感，带缝线装饰边框，按板块用不同色块区分 |
| 寄养交接单页 | 喂食板块 | 绿色系色块，食物图标装饰 |
| 寄养交接单页 | 清洁板块 | 蓝色系色块，水滴图标装饰 |
| 寄养交接单页 | 外出板块 | 橙色系色块，爪印图标装饰 |
| 寄养交接单页 | 健康观察板块 | 红色系色块，心率图标装饰 |
| 每日打卡页 | 打卡日历 | 横向时间轴，每日节点显示状态图标（✓完成/!异常/○未打卡） |
| 每日打卡页 | 打卡表单 | 清单式勾选，状态选择用圆角按钮组，照片上传区带虚线边框 |
| 留言板 | 留言列表 | 便签纸风格卡片，重要留言用珊瑚橙标签标记，带图钉装饰 |
| 统计页 | 打卡统计 | 环形进度图展示完成率，柱状图展示每日打卡明细 |
| 统计页 | 异常时间线 | 垂直时间轴，异常节点用红色标记，带展开详情 |
| 统计页 | 用品消耗 | 进度条式展示剩余量，低于30%变橙色提醒 |

### 4.3 响应式设计

- 桌面端优先设计，交接单在宽屏下展示完整四板块布局
- 平板端两栏布局，交接单板块改为2×2网格
- 移动端单栏布局，板块纵向堆叠，打卡操作优化触摸区域

### 4.4 动效设计

- 页面切换：淡入淡出过渡
- 卡片交互：悬浮上浮+阴影加深，点击轻微缩放反馈
- 打卡完成：勾选时弹出小爪印动画
- 照片上传：拖拽区域呼吸动画
- 统计数据：数字滚动动画
