## 1. 产品概述

手账贴纸库存册 — 一款面向手账爱好者的素材管理工具，帮助用户记录贴纸、胶带、便签、印章的库存信息，避免重复购买和收纳混乱，同时提供使用记录、搭配灵感和数据统计功能。

- 解决手账玩家"买了不记得、重复囤货、找不到素材"的痛点
- 让每一张贴纸、每一卷胶带都被看见和用起来

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 无需注册，本地使用 | 全部功能 |

### 2.2 功能模块
1. **首页**: 素材分组展示、库存预警提示、快速入口
2. **素材管理页**: 添加/编辑/查看素材详情
3. **使用记录页**: 记录手账制作时使用的素材
4. **搭配灵感页**: 创建和管理主题搭配方案
5. **统计页**: 用量统计、购买分析、闲置素材提醒

## 3. 核心流程

### 素材添加流程
用户点击添加 → 选择素材类型 → 填写信息（名称/品牌/主题/颜色/数量/价格/收纳位置）→ 上传照片 → 保存入库

### 使用记录流程
用户点击新建使用记录 → 选择手账本 → 选择使用的素材 → 填写每种素材用量 → 确认保存 → 对应素材库存自动减少

### 搭配灵感流程
用户创建搭配 → 输入主题名称（如"秋日咖啡"）→ 从素材库中添加素材 → 保存搭配方案

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 暖米色(#F5E6D3)为底，搭配奶茶棕(#8B6F47)和柔粉(#E8B4B8)
- **辅助色**: 薄荷绿(#A8D5BA)用于成功/充足状态，珊瑚橙(#E8927C)用于警告/不足状态
- **按钮风格**: 圆角柔和，带轻微阴影，hover时微微上浮
- **字体**: 标题使用衬线体营造手写温度感，正文使用无衬线保证可读性
- **布局**: 卡片式布局，带牛皮纸纹理背景，模拟手账本质感
- **图标风格**: 线条手绘风格，使用lucide-react图标库
- **装饰元素**: 卡片角落有和纸胶带装饰效果，分割线使用虚线模拟缝线

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 素材分组卡片 | 四宫格卡片，每张卡片带和纸胶带装饰，显示图标+类型名+数量 |
| 首页 | 库存预警区 | 横向滚动卡片，珊瑚橙边框为不足提示，蓝色边框为囤积提示 |
| 首页 | 最近使用 | 时间轴样式，每条记录带小图标 |
| 素材管理页 | 素材网格 | 瀑布流网格，每张卡片含照片缩略图+名称+数量标签 |
| 素材管理页 | 筛选栏 | 顶部标签式筛选，带颜色圆点 |
| 使用记录页 | 记录列表 | 日期分组，每条记录展示手账本名+素材小卡片 |
| 搭配灵感页 | 灵感卡片 | 大图封面+标题+素材数量徽标，带胶带装饰 |
| 统计页 | 数据卡片 | 圆角卡片带图标，数字突出显示 |
| 统计页 | 闲置列表 | 素材缩略图+名称+入库天数 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度1024px
- 平板适配：卡片从4列变2列
- 手机适配：单列布局，底部导航栏
