## 1. 产品概述

小区电动车电池体检小工具——为物业和车主提供电池健康管理的全流程解决方案。解决电池老化无人监控、衰减风险难发现的痛点，通过自助体检+集中检测的方式，降低安全隐患。

- 目标用户：小区电动车车主、物业管理员
- 核心价值：电池衰减早发现、风险早预警、集中检测提效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 车主 | 手机号注册 | 录入车辆、自助体检、报名集中检测、查看统计 |
| 物业管理员 | 管理员邀请码注册 | 发布集中检测场次、查看统计、管理车主数据 |

### 2.2 功能模块

1. **首页**：电池状态分区看板（正常 / 该检测 / 疑似衰减 / 危险提醒）、快捷操作入口
2. **车辆管理**：录入/编辑车辆与电池信息
3. **电池体检**：填写检测数据、系统自动评级、历史体检记录
4. **集中检测**：物业发布场次、车主报名排队
5. **统计中心**：高风险电池数量、平均衰减率、楼栋检测积极性排行

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 状态分区看板 | 按正常（绿）、该检测（黄）、疑似衰减（橙）、危险提醒（红）四分区展示车主的所有电池，每张卡片显示车辆名、电池型号、衰减等级、上次体检日期 |
| 首页 | 快捷操作 | 一键体检、报名检测、查看统计的入口按钮 |
| 车辆管理 | 车辆列表 | 展示车主所有车辆卡片，支持新增/编辑/删除 |
| 车辆管理 | 车辆表单 | 录入车辆品牌型号、电池型号、购买日期、标称续航、充电习惯（每天充/隔天充/三天一充）、异常发热记录（有/无/偶尔）、楼栋号 |
| 电池体检 | 体检表单 | 填写电压(V)、充满耗时(小时)、实际骑行距离(km)、拍照上传，系统计算衰减等级 |
| 电池体检 | 体检结果 | 显示衰减等级（A健康/B轻微衰减/C明显衰减/D严重衰减/E危险）、衰减说明、建议措施 |
| 电池体检 | 历史记录 | 该电池的所有体检记录时间线 |
| 集中检测 | 场次列表 | 物业发布的检测场次卡片，显示日期、时段、地点、名额/已报名数 |
| 集中检测 | 发布场次 | 物业填写日期、时段、地点、最大名额，发布新场次 |
| 集中检测 | 报名与排队 | 车主选择场次报名，报名后显示排队号和预计时间 |
| 统计中心 | 风险概览 | 高风险(E级)电池数量、各级别电池占比饼图 |
| 统计中心 | 衰减趋势 | 全小区平均衰减等级趋势折线图 |
| 统计中心 | 楼栋排行 | 各楼栋检测完成率和积极性排行榜 |

## 3. 核心流程

**车主自助体检流程**：车主登录 → 首页查看电池状态 → 点击"一键体检" → 选择车辆 → 填写检测数据 → 系统评级 → 查看结果和建议

**集中检测流程**：物业发布场次 → 车主浏览场次 → 报名获取排队号 → 按号前往检测 → 现场录入数据 → 系统评级

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰(zinc-900)底 + 翠绿(emerald)强调色，传达"安全监控"的专业感
- **辅助色**：状态色——绿(emerald)、黄(amber)、橙(orange)、红(red)四级预警色
- **按钮风格**：圆角微凸(rounded-lg + shadow-sm)，主按钮实色填充，次按钮描边
- **字体**：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式布局
- **图标**：lucide-react 图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 状态分区看板 | 四色分区网格，每个分区卡片带状态色边框、电池图标、衰减标签 |
| 首页 | 快捷操作 | 底部固定操作栏，三个圆角按钮带图标 |
| 车辆管理 | 车辆列表 | 竖向卡片列表，左图右文布局，右上角编辑/删除图标 |
| 车辆管理 | 车辆表单 | 弹出式模态框，分步表单(基本信息→电池信息→充电习惯) |
| 电池体检 | 体检表单 | 全屏表单页，输入框带单位标注，照片区域支持拖拽上传 |
| 电池体检 | 体检结果 | 结果卡片，大号等级字母 + 状态色背景 + 建议列表 |
| 电池体检 | 历史记录 | 时间线组件，左侧日期右侧数据 |
| 集中检测 | 场次列表 | 卡片网格，每张显示日历图标+日期+地点+进度条(名额) |
| 集中检测 | 发布场次 | 模态框表单，物业角色专属 |
| 集中检测 | 报名与排队 | 报名后展示排队号大数字卡片+动画 |
| 统计中心 | 风险概览 | 顶部统计数字卡片(大号数字+小标签)+环形图 |
| 统计中心 | 衰减趋势 | 折线图区域 |
| 统计中心 | 楼栋排行 | 横向条形图排行 |

### 4.3 响应式设计

- 桌面优先（1280px+），左侧导航+右侧内容
- 平板(768-1280px)：导航折叠为顶部栏，内容区自适应
- 手机(<768px)：底部Tab导航，卡片单列

### 4.4 动效设计

- 状态分区卡片：悬停时微微上浮 + 阴影加深
- 体检结果：等级字母从缩小到放大的弹跳动画
- 排队号：数字翻滚动画
- 页面切换：淡入滑动过渡
