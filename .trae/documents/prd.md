## 1. 产品概述

老人慢病复诊提醒系统——帮助家属系统管理高血压、糖尿病、心脏病等慢性病的复诊安排和长期用药。解决家属看护中「记不住复诊时间、搞不清用药方案、异常指标发现晚、家属分工不明确」的痛点。

- 目标用户：有老人的家庭，尤其是多名家属共同照护的场景
- 核心价值：把散落在聊天记录和纸质病历中的慢病信息集中管理，通过日历视图和异常预警，让家属不错过任何一次复诊和异常情况

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 家属管理员 | 创建老人档案的家庭成员 | 增删改查所有数据、分配家属分工 |
| 家属成员 | 参与照护的其他家庭成员 | 查看所有数据、接受分工任务 |

### 2.2 功能模块
1. **首页（看护日历）**：日历视图展示每日任务、异常预警、今日待办
2. **老人档案页**：管理老人基本信息和医保信息
3. **慢病管理页**：每个慢病的详细记录、用药方案、复诊周期
4. **复诊记录页**：每次复诊后的检查结果、医生建议、药量调整
5. **家属分工页**：挂号、陪诊、买药等任务分配与追踪
6. **统计页**：复诊按时率、药费和检查费用统计

|-----------|-------------|----------|

## 3. 核心流程

1. **建档流程**：家属添加老人档案 → 为老人添加慢病信息 → 设置复诊周期和用药方案
2. **日常看护流程**：打开首页查看日历 → 查看今日待办 → 按计划执行（量血压/服药/检查）→ 记录指标数据
3. **复诊流程**：日历提醒复诊 → 家属分工（谁挂号/谁陪诊）→ 复诊完成 → 填写复诊记录 → 系统自动生成下次提醒
4. **异常预警流程**：系统检测连续异常指标 → 首页红色预警卡片 → 家属关注并处理

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：温暖的珊瑚橙（#E8725A）搭配深青灰（#2D3748），传递温暖而专业的家庭照护氛围
- 辅助色：淡米色（#FDF6EC）背景，柔和绿色（#48BB78）表示正常，警示红（#E53E3E）表示异常
- 按钮风格：圆角8px，轻微阴影，悬停时微妙上浮
- 字体：思源黑体/Noto Sans SC 作为中文主字体，数字使用等宽风格便于阅读指标数据
- 布局风格：卡片式布局，顶部导航切换页面，左侧可展开老人选择面板
- 图标风格：使用 lucide-react 线性图标，温暖简洁

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI要素 |
|-----------|-------------|----------|
| 首页 | 看护日历 | 月历网格，每个日期格可显示任务圆点标记，选中日期弹出任务详情面板 |
| 首页 | 今日待办 | 左侧日历下方的任务卡片列表，按时序排列，紧急任务带红色左边框 |
| 首页 | 异常预警 | 顶部醒目的红色渐变横幅，脉冲动画提示紧急程度 |
| 老人档案 | 档案卡片 | 大号头像区域+基本信息，底部快捷按钮（查看慢病/复诊记录） |
| 老人档案 | 编辑表单 | 分组表单，每组有标题线分隔，医保信息折叠展开 |
| 慢病管理 | 慢病标签 | 顶部横向标签栏切换不同慢病，标签带颜色标识 |
| 慢病管理 | 指标面板 | 目标指标和当前数值对比展示，异常数值红色高亮 |
| 复诊记录 | 时间线 | 左侧时间轴+右侧内容卡片，清晰展示复诊历史 |
| 家属分工 | 看板 | 三列看板布局（待完成/进行中/已完成），任务卡片可拖拽 |
| 统计页 | 图表 | 柱状图展示费用，环形图展示按时率，月度趋势折线图 |

### 4.3 响应式设计
- 桌面优先设计，大屏利用空间展示日历+任务双栏
- 平板适配：日历缩小但保留日任务标记
- 手机适配：底部Tab导航，日历改为周视图，看板改为列表

### 4.4 无障碍设计
- 所有交互元素支持键盘操作
- 异常预警除颜色外增加图标标识
- 字体大小适配老年人阅读需求
