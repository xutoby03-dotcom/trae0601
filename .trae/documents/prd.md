## 1. 产品概述

家庭饮水提醒杯架 —— 一款面向家庭的日常饮水追踪与提醒工具，帮助老人和孩子记住每天喝了多少水。
- 核心问题：家庭成员（尤其是老人和孩子）日常饮水量难以追踪，容易忘记喝水或饮水不足
- 目标用户：关注家庭健康的用户，需要为多个家庭成员（老人、孩子等）管理饮水计划

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 |
|------|------|
| 家庭管理员 | 添加/编辑家庭成员，查看全家饮水统计 |
| 家庭成员 | 被添加的家庭成员，有独立饮水目标和记录 |

### 2.2 功能模块

1. **首页**：杯子阵列视图，全家今日饮水进度一览，快捷记录按钮
2. **成员管理页**：添加/编辑家庭成员，设置饮水目标和提醒
3. **饮水记录页**：选择饮品类型记录饮水，支持补记历史
4. **统计页**：一周达标率、易忘时段分析、个人平均饮水量

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 杯子阵列 | 显示所有家庭成员的杯子卡片，水位动画表示今日饮水进度，杯子颜色区分成员 |
| 首页 | 快捷记录 | 点击杯子上的 "+" 按钮一键记录一杯水（默认常用杯容量） |
| 首页 | 今日状态标签 | "还差 xxx ml"、"快达标了"、"睡前别喝太多" 等状态提示 |

| 成员管理页 | 成员列表 | 显示所有家庭成员卡片，支持编辑和删除 |
| 成员管理页 | 添加/编辑表单 | 填写姓名、年龄、目标饮水量、常用杯容量、是否需要少喝水、提醒时段 |
| 饮水记录页 | 饮品选择 | 白水、咖啡、茶、饮料等分类，不同饮品折算不同白水比例 |

| 统计页 | 平均饮水量 | 每个成员日均饮水量对比，饮品类型占比 |

## 3. 核心流程

### 3.1 快捷饮水记录流程
用户打开首页 → 看到全家杯子阵列 → 点击某成员杯子上的 "+" 按钮 → 系统自动以该成员常用杯容量记录一杯白水 → 杯子水位上升动画 → 若达标则显示祝贺提示

### 3.2 详细记录流程
用户点击详细记录按钮 → 选择成员 → 选择饮品类型（白水/咖啡/茶/饮料）→ 输入容量 → 可选场景标签（运动/睡前/感冒）→ 确认记录 → 返回首页更新进度

### 3.3 补记流程
用户进入饮水记录页 → 点击"补记"→ 选择日期和时间 → 选择成员和饮品 → 输入容量 → 确认补记

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：清新海洋蓝 (#4FC3F7) 搭配暖白 (#FAFAFA) 背景，辅以薄荷绿 (#81C784) 表示达标状态
- **次色调**：珊瑚橙 (#FF8A65) 用于提醒和警告，淡紫 (#CE93D8) 用于特殊场景
- **按钮风格**：圆角胶囊按钮，3D 微凸起效果，点击有水波纹动画
- **字体**：标题使用 Quicksand（圆润可爱），正文使用 Noto Sans SC（清晰易读）
- **布局风格**：卡片式布局，杯子形状的进度可视化，圆润友好的整体风格
- **图标风格**：圆润线条图标，配合水滴、杯子等主题元素
- **动画**：杯子水位上升的流体动画，达标时的水花庆祝效果，页面切换的波纹过渡

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | 杯子阵列 | 圆角卡片网格，每个卡片包含杯子形状水位动画、成员头像、进度百分比、状态标签 |
| 首页 | 快捷记录按钮 | 杯子卡片右上角浮动 "+" 圆形按钮，带水波纹点击效果 |
| 首页 | 特殊提醒横幅 | 顶部滑入横幅，珊瑚橙背景，图标+文字提示 |
| 成员管理页 | 成员列表 | 水平滚动卡片列表，每张卡片显示成员信息和编辑按钮 |
| 成员管理页 | 添加/编辑表单 | 全屏滑入表单面板，分步骤填写，滑块选择容量 |
| 饮水记录页 | 饮品选择 | 横向滚动的饮品图标卡片（水滴/咖啡杯/茶壶/饮料瓶），选中高亮 |
| 饮水记录页 | 容量输入 | 圆形滑块或数字输入框，带常用杯容量快捷按钮 |
| 饮水记录页 | 场景标签 | 可多选的胶囊标签组（运动🏃/睡前🌙/感冒🤧） |
| 统计页 | 周达标率 | 7天柱状图，达标绿色/未达标灰色 |
| 统计页 | 易忘时段 | 24小时热力图，颜色深浅表示记录频率 |
| 统计页 | 平均饮水量 | 横向对比柱状图，每人不同颜色 |

### 4.3 响应式设计

- 桌面端优先设计，最大宽度 1280px 居中
- 平板适配：杯子阵列 2 列布局
- 手机适配：杯子阵列单列，底部固定快捷记录栏
- 触屏优化：按钮最小 44px 触控区域，滑块操作友好

### 4.4 视觉动效

- 杯子水位：CSS 渐变 + transition 实现水位上升动画
- 达标庆祝：水花粒子效果（CSS animation）
- 页面切换：淡入淡出 + 轻微上移过渡
- 提醒横幅：从顶部滑入，3秒后自动收起
- 按钮交互：hover 放大 + 阴影加深，点击缩放回弹
