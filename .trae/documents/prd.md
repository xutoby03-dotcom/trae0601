## 1. 产品概述

家庭保险续费提醒工具——帮助家庭集中管理车险、重疾险、医疗险、意外险等各类保单，避免忘记续费和重复购买，及时发现保障缺口与重叠。
- 面向有家庭保险管理需求的普通用户，解决保单分散、续费遗忘、重复投保、保障缺口等问题
- 让每个家庭成员的保障状况一目了然，用智能提醒代替手动记忆

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 家庭管理员 | 免注册，本地使用 | 添加/编辑/删除保单、续费记录、理赔记录，查看统计 |

### 2.2 功能模块
1. **首页**：保单分组展示（快缴费/快到期/保障中/已失效）、快捷操作入口、保障提醒卡片
2. **添加/编辑保单页**：表单录入保单信息、上传保单照片
3. **个人保障视图页**：按被保人查看保障详情、重叠/缺口提醒
4. **续费记录页**：续费历史、金额与付款凭证
5. **理赔记录页**：出险原因、提交材料、赔付金额
6. **统计页**：年保费总览、人均保障金额、快到期清单

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

用户打开应用 → 首页看到保单分组和提醒 → 点击"添加保单"填写信息 → 系统自动判断状态分组 → 查看个人保障视图发现缺口/重叠 → 对快到期保单进行续费记录 → 发生理赔时录入理赔记录 → 统计页查看年度保费和保障概况

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深靛蓝(#1e3a5f)，辅助色：暖琥珀(#f59e0b)用于提醒和强调
- 按钮风格：圆角(8px)、带微妙阴影的扁平按钮
- 字体：思源黑体/Noto Sans SC，标题16-20px加粗，正文14px常规
- 布局风格：左侧导航栏 + 右侧内容区，卡片式布局
- 图标风格：线性图标(Lucide)

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 保单分组卡片 | 四列卡片，每列不同色系标识状态，卡片内显示保单摘要 |
| 首页 | 提醒横幅 | 顶部横幅，琥珀色背景，图标+文字提醒 |
| 首页 | 快捷操作 | 三个圆形图标按钮，hover放大效果 |
| 添加/编辑保单页 | 表单 | 分组表单，标签浮动效果，日期选择器 |
| 添加/编辑保单页 | 照片上传 | 虚线边框拖拽区，缩略图预览 |
| 个人保障视图页 | 被保人列表 | 左侧竖向头像+姓名列表 |
| 个人保障视图页 | 保障矩阵 | 险种×状态色块网格，绿色=有保障，红色=缺口，黄色=重叠 |
| 续费记录页 | 续费列表 | 时间线样式，左侧时间轴+右侧卡片 |
| 理赔记录页 | 理赔列表 | 卡片列表，状态标签(处理中/已赔付/已拒赔) |
| 统计页 | 图表区 | 饼图+柱状图，数据卡片汇总 |

### 4.3 响应式
- 桌面优先设计，最小宽度1024px
- 平板端导航栏收起为汉堡菜单
- 移动端单列布局，底部Tab导航
