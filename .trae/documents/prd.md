## 1. 产品概述

家庭空调清洗管家 —— 一款帮助家庭管理空调清洗计划的实用工具。解决夏天开机才发现滤网积灰、忘记上次清洗时间、家人分工不明确等痛点。面向有2台以上空调的家庭用户，通过分组提醒、清洗记录、换季检查清单和费用统计，让空调维护不再遗忘。

## 2. 核心功能

### 2.1 用户角色
无需注册登录，面向家庭成员共同使用，数据存储在本地浏览器。

### 2.2 功能模块
1. **首页**：空调状态分组展示、换季提醒入口、快捷操作
2. **空调管理页**：添加/编辑空调信息
3. **空调详情页**：清洗记录列表、换季检查清单、家人分工
4. **添加记录页**：记录清洗详情（费用、照片、问题等）
5. **统计页**：年度费用、问题频次、清洗周期分析

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | 状态分组 | 按三组展示空调：快该洗（距上次清洗60-90天）、已经超期（超过90天）、今年洗过（90天内洗过） |
| 首页 | 换季提醒卡片 | 显示即将到期的换季检查项（遥控器电池、排水管、外机遮挡） |
| 首页 | 快捷操作 | 一键添加空调、快速记录清洗 |
| 空调管理页 | 基本信息表单 | 填写房间名、品牌型号、上次清洗日期、滤网类型（普通过滤网/HEPA/活性炭）、是否需要高空作业、保修电话 |
| 空调详情页 | 清洗记录时间线 | 展示所有清洗记录，含清洗人、费用、前后照片、异味/漏水问题标记 |
| 空调详情页 | 换季检查清单 | 可勾选的检查项：遥控器电池、排水管、外机遮挡物、滤网状态 |
| 空调详情页 | 家人分工 | 分配任务：谁联系师傅、谁在家等候、谁负责检查 |
| 添加记录页 | 清洗详情表单 | 清洗人姓名、费用、清洗前后照片上传、异味/漏水问题勾选、备注 |
| 统计页 | 年度费用统计 | 当年总清洗费用、各空调费用对比 |
| 统计页 | 问题分析 | 哪台空调最常出问题（异味/漏水频次排名） |
| 统计页 | 清洗周期 | 平均多久洗一次、距下次建议清洗天数 |

## 3. 核心流程

用户打开应用 → 首页看到空调分组状态 → 点击"添加空调"录入家中空调信息 → 根据分组提示发现超期空调 → 点击空调卡片进入详情 → 记录清洗（填写费用、上传照片、标记问题）→ 换季时查看提醒清单 → 家人分工协作 → 统计页查看年度维护情况

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：清爽天蓝 (#0EA5E9) + 暖橙提醒 (#F97316)
- 辅助色：薄荷绿（已清洗）#34D399、珊瑚红（超期）#F43F5E
- 按钮风格：圆角大按钮，微阴影，hover时上浮
- 字体：Noto Sans SC（中文），搭配 DM Sans（数字/英文）
- 布局：卡片式布局，顶部导航栏，底部Tab栏（首页/添加/统计）
- 图标风格：线条图标（lucide-react），搭配空调/清洗相关的视觉隐喻

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 首页 | 状态分组 | 三色分组卡片（蓝/红/绿），每组内空调横向滚动卡片，显示房间名、品牌、距上次清洗天数 |
| 首页 | 换季提醒 | 橙色渐变卡片，图标+文字列表，可展开详细内容 |
| 空调管理页 | 表单 | 分组表单区域，下拉选择+日期选择器+开关，底部固定保存按钮 |
| 空调详情页 | 时间线 | 左侧时间轴，右侧清洗记录卡片，照片缩略图可点击放大 |
| 空调详情页 | 检查清单 | 勾选框列表，完成后显示对勾动画 |
| 空调详情页 | 家人分工 | 人物头像+任务标签，可拖拽分配 |
| 添加记录页 | 表单 | 照片上传区域（拖拽/点击），费用输入，问题标签选择 |
| 统计页 | 图表区域 | 柱状图（费用对比）、饼图（问题分布）、数字卡片（关键指标） |

### 4.3 响应式设计
- 桌面优先，最大宽度1200px居中
- 移动端适配：卡片单列、底部Tab导航、表单全宽
- 触摸优化：按钮最小44px点击区域，卡片支持滑动操作
