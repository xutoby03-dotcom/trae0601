## 1. 产品概述

音频可视化分析工具 - 为音乐爱好者打造的专业级音频处理Web应用。支持多种音频格式上传、麦克风实时录音、四种动态可视化模式、智能音频信息分析、十段均衡器调节、时间轴标记以及音频切片导出。

- 核心价值：让音乐可视化、可分析、可编辑，提供沉浸式的音乐体验
- 目标用户：音乐爱好者、音频创作者、DJ、学生及教育工作者

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册，直接使用 | 所有功能完全免费开放 |

### 2.2 功能模块
1. **音频输入模块**：文件上传(MP3/WAV/FLAC)、麦克风实时录音
2. **可视化模块**：频谱柱状图、波形线、圆环旋转、3D山脉四种模式
3. **信息分析模块**：时长、比特率、采样率、声道数、BPM自动识别
4. **EQ均衡模块**：十段参数均衡器，实时调节生效
5. **播放控制模块**：播放/暂停、上一首/下一首、进度条拖拽
6. **标记模块**：时间轴上添加标签备注
7. **切片导出模块**：选择起止时间，一键导出MP3片段

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主工作台 | 顶部工具栏 | 文件上传、录音按钮、可视化模式切换 |
| 主工作台 | 中央画布 | 大型可视化显示区域，响应式适配 |
| 主工作台 | 信息面板 | 显示音频元数据和分析结果 |
| 主工作台 | EQ面板 | 十段均衡器滑块控制 |
| 主工作台 | 播放控制栏 | 播放按钮、进度条、时间显示 |
| 主工作台 | 标记面板 | 标记列表管理、添加/删除标记 |
| 主工作台 | 切片面板 | 起止时间选择、导出下载 |

## 3. 核心流程

用户上传音频文件或启动麦克风录音 → 系统自动分析音频信息并显示 → 用户选择可视化模式观看动态效果 → 通过EQ调节音效 → 在精彩位置添加标记 → 选择片段导出下载

```mermaid
flowchart LR
    A["开始"] --> B["上传音频/启动录音"]
    B --> C["音频信息自动分析"]
    C --> D["选择可视化模式"]
    D --> E["播放+EQ调节"]
    E --> F["添加时间轴标记"]
    F --> G["选择切片范围"]
    G --> H["导出MP3下载"]
    H --> I["结束"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深黑 (#0a0a0f) 背景，霓虹蓝 (#00d4ff) 为主色，紫罗兰 (#a855f7) 为辅助色
- **按钮风格**：玻璃拟态 (Glassmorphism)，圆角8px，悬浮发光效果
- **字体**：展示字体使用 Orbitron，正文字体使用 JetBrains Mono
- **布局风格**：三栏布局，中央画布最大，左右功能面板可折叠
- **视觉效果**：光晕、渐变、粒子效果、科技感网格背景

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主工作台 | 中央画布 | 全屏Canvas、动态粒子背景、可视化动画 |
| 主工作台 | 左侧面板 | 音频信息卡片、EQ滑块组、玻璃拟态边框 |
| 主工作台 | 底部控制栏 | 播放按钮组、进度条、时间显示、标记按钮 |
| 主工作台 | 右侧面板 | 标记列表、切片控制、导出按钮 |

### 4.3 响应性
- 桌面端优先设计，支持1280px以上最佳体验
- 平板端自动折叠侧边面板，可展开
- 移动端竖屏时上下堆叠布局

### 4.4 视觉特效
- 可视化区域添加轻微辉光效果
- 按钮和滑块交互时带有霓虹发光动画
- 模式切换时带有平滑过渡动画
- 背景添加低透明度的网格和粒子动效
