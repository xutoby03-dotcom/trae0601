## 1. 产品概述

老人理发上门服务预约管理系统，专为社区养老服务设计，解决老人行动不便导致的理发难问题。系统涵盖老人档案管理、在线预约、理发师出发确认、服务完成记录和数据看板全流程。

- **目标用户**：社区养老服务人员、上门理发师、老人家属
- **核心价值**：减少反复确认成本，提升上门服务效率，保障服务质量
- **产品定位**：社区养老便民服务数字化管理工具

## 2. 核心功能

### 2.1 用户角色

| 角色 | 描述 | 核心权限 |
|------|------|----------|
| 管理员/调度员 | 社区服务中心工作人员 | 档案管理、预约调度、看板查看 |
| 理发师 | 上门服务的理发师 | 查看预约、出发确认、服务记录 |
| 家属（可选） | 老人的家属 | 查看预约记录、服务评价 |

### 2.2 功能模块

1. **数据看板**：今日上门、待确认、特殊需求、超时未到、常客复约提醒
2. **老人档案管理**：老人信息的增删改查
3. **预约管理**：新建预约、预约列表、预约详情
4. **理发师出发确认**：工具清单检查、出发确认
5. **服务完成记录**：发型照片、费用、满意度、下次建议时间

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据看板 | 统计卡片 | 显示今日上门、待确认、特殊需求、超时未到数量 |
| 数据看板 | 预约列表 | 分类展示各类状态的预约卡片 |
| 数据看板 | 复约提醒 | 显示常客复约提醒列表 |
| 老人档案 | 档案列表 | 分页展示所有老人档案，支持搜索 |

## 3. 核心流程

```mermaid
flowchart LR
    A["创建老人档案"] --> B["发起理发预约"]
    B --> C["选择理发师和时间"]
    C --> D["预约确认（待确认状态）"]
    D --> E["理发师出发前工具检查"]
    E --> F["上门服务中"]
    F --> G["服务完成记录"]
    G --> H["满意度评价 & 下次预约建议"]
    H --> I["档案更新 & 复约提醒"]
```

主要流程说明：
1. 管理员为老人建立档案，记录基本信息和特殊需求
2. 家属或管理员发起预约，选择理发师、时间和服务项目
3. 预约进入待确认状态，理发师确认后安排出发
4. 理发师出发前需逐项确认工具清单
5. 服务完成后记录发型照片、费用和满意度
6. 系统自动生成常客复约提醒

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：温暖橙红色系 (#FF7A45)，传递关怀与温暖的感觉
- **辅助色**：柔和的米白色背景，浅蓝绿色作为成功状态色
- **中性色**：深灰文字，确保老年友好的高对比度
- **按钮风格**：大圆角按钮，尺寸偏大，方便触控操作
- **字体**：清晰易读的无衬线字体，字号偏大（正文不小于14px）
- **布局风格**：卡片式布局，留白充足，信息层级清晰
- **图标风格**：线性图标，简洁明了，配合文字标签

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 数据看板 | 顶部导航 | Logo、页面标题、用户头像 |
| 数据看板 | 统计卡片 | 四色卡片网格，数字+标签+图标 |
| 数据看板 | 看板列 | 多列拖拽式看板，每列显示对应状态预约 |
| 数据看板 | 复约提醒 | 侧栏列表，带时间提醒标识 |
| 老人档案 | 列表页 | 搜索栏 + 卡片网格列表，显示照片和基本信息 |
| 老人档案 | 详情页 | 左侧照片，右侧信息分组展示 |
| 老人档案 | 表单页 | 分组表单，大输入框，清晰的标签 |
| 预约管理 | 列表页 | 时间线/日历视图 + 状态筛选 |
| 预约管理 | 表单页 | 分步表单，老人选择 → 时间服务 → 确认 |
| 出发确认 | 检查清单 | 可勾选的清单项目，带图标和描述 |
| 服务完成 | 记录页 | 照片上传区 + 表单 + 星级评分 |

### 4.3 响应式

- 桌面端优先设计，适配平板和手机
- 移动端采用单列布局，卡片堆叠
- 触控目标尺寸不小于 44×44px
- 关键操作按钮放大显示

### 4.4 无障碍设计

- 文字与背景对比度不低于 4.5:1
- 表单控件均有关联标签
- 图标配合文字说明
- 支持键盘导航
- 状态变化有明确的视觉反馈
