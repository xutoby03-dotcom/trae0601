## 1. 产品概述

社区合唱队曲谱借阅管理系统，帮助老师高效管理曲谱的借阅、归还和库存追踪，告别纯靠记忆的管理方式。

- 核心目标：解决曲谱借阅登记、归还检查、库存盘点等管理痛点
- 目标用户：社区合唱队老师/管理员
- 核心价值：提升管理效率，减少曲谱丢失和损坏，清晰掌握库存状态

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 管理员（老师） | 本地应用，无需登录 | 全部功能：曲谱管理、队员管理、借阅登记、归还检查、看板查看 |

### 2.2 功能模块

1. **看板首页**：待归还曲谱、缺谱声部、破损曲谱、下次排练曲目、需加印数量
2. **曲谱档案**：曲谱列表、新增、编辑、删除、详情查看
3. **队员档案**：队员列表、新增、编辑、删除、详情查看
4. **借阅管理**：借阅登记、归还检查、借阅记录查询

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 看板首页 | 待归还卡片 | 展示所有未归还的曲谱，含借阅人、借阅日期、预计归还 |
| 看板首页 | 缺谱声部卡片 | 按声部统计库存不足的曲谱及缺额数量 |
| 看板首页 | 破损曲谱卡片 | 展示标记为破损/缺页/涂写的曲谱列表 |
| 看板首页 | 下次排练卡片 | 展示下次排练曲目及所需曲谱清单 |
| 看板首页 | 加印统计卡片 | 统计需要重印的曲谱数量汇总 |
| 曲谱档案 | 曲谱列表 | 表格展示所有曲谱，支持按声部、状态筛选和搜索 |

## 3. 核心流程

### 3.1 借阅流程

老师在排练前为队员登记曲谱借阅 → 选择曲谱和队员 → 填写借阅信息 → 系统记录借阅状态 → 库存减少可用数量

```mermaid
flowchart LR
    A["打开借阅登记"] --> B["选择曲谱"]
    B --> C["选择队员"]
    C --> D["填写排练日期和预计归还"]
    D --> E["确认借阅"]
    E --> F["更新曲谱库存状态"]
    F --> G["生成借阅记录"]
```

### 3.2 归还流程

队员归还曲谱 → 老师检查曲谱状态 → 登记检查结果（缺页/破损/涂写）→ 标记是否需要重印 → 更新库存状态

```mermaid
flowchart LR
    A["选择待归还记录"] --> B["检查缺页情况"]
    B --> C["检查破损情况"]
    C --> D["检查涂写情况"]
    D --> E["标记是否需要重印"]
    E --> F["确认归还"]
    F --> G["更新曲谱状态和库存"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨绿色（#1a4d2e），传递优雅、文艺、和谐的合唱氛围
- **辅助色**：暖金色（#d4a574），用于强调和交互元素
- **背景色**：米白色（#faf8f5），温暖舒适的阅读感
- **按钮风格**：圆角矩形，轻微阴影，悬停有微妙上浮效果
- **字体**：标题使用衬线字体（Noto Serif SC），正文使用清晰易读的无衬线字体
- **布局风格**：卡片式布局，清晰的信息层级，充足的留白
- **图标风格**：线性图标，简洁优雅

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 看板首页 | 数据卡片 | 五个统计卡片横向排列，数字醒目，图标装饰 |
| 看板首页 | 列表区域 | 待归还、破损曲谱等列表使用卡片式展示 |
| 曲谱档案 | 顶部操作栏 | 搜索框、筛选下拉、新增按钮 |
| 曲谱档案 | 数据表格 | 斑马纹、悬停高亮、操作列 |
| 曲谱档案 | 表单弹窗 | 表单分组布局，照片预览，确认/取消按钮 |
| 队员档案 | 同曲谱档案 | 类似的列表和表单设计，保持一致性 |
| 借阅管理 | 标签切换 | 借阅登记/归还检查/借阅记录三个标签页 |

### 4.3 响应式

- 桌面端优先设计（1280px 以上）
- 平板端（768-1280px）：卡片自适应换行，表格支持横向滚动
- 移动端（768px 以下）：单列布局，侧边栏收起为汉堡菜单

### 4.4 动效设计

- 页面切换：淡入淡出过渡
- 卡片悬停：轻微上浮 + 阴影加深
- 按钮点击：缩放反馈
- 数据加载：骨架屏占位
- 弹窗出现：从中心缩放 + 背景遮罩淡入
