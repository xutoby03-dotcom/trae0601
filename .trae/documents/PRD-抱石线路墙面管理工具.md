## 1. 产品概述

抱石线路墙面管理工具是一款面向攀岩馆的运营管理系统，帮助工作人员高效管理抱石墙面的线路、岩点和顾客反馈。通过可视化墙面示意图，工作人员可以直观地查看每条线路的颜色、难度、开线人和拆线日期，并快速记录岩点问题。顾客反馈可汇总到对应线路，由开线人复核后决定保留、微调或下线。

- 目标用户：攀岩馆工作人员、巡场员、开线人
- 核心价值：提升线路管理效率，改善顾客体验，延长岩点使用寿命

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 工作人员 | 默认登录 | 查看墙面、巡场记录岩点问题、提交顾客反馈 |
| 开线人 | 默认登录 | 线路管理、查看反馈、复核反馈、决定线路状态 |

### 2.2 功能模块

1. **墙面总览页**：可视化墙面示意图、线路列表、状态筛选
2. **巡场记录**：点击岩点记录问题（松动、磨损、缺螺丝、落脚点太滑）
3. **顾客反馈**：按线路提交难度/动作反馈，查看反馈汇总
4. **线路管理**：新增/编辑线路，设置颜色、难度、开线人、拆线日期
5. **反馈复核**：开线人查看反馈，决定保留/微调/下线

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 墙面总览 | 墙面示意图 | SVG可交互墙面，显示岩点位置和线路颜色，点击岩点查看详情 |
| 墙面总览 | 线路列表 | 侧边栏展示所有线路，支持按难度/颜色/状态筛选 |
| 墙面总览 | 状态筛选 | 快速筛选正常/需维护/待复核/即将下线的线路 |
| 巡场记录 | 问题记录弹窗 | 选择岩点后记录问题类型、严重程度、备注 |
| 巡场记录 | 问题标记 | 有问题的岩点在墙面上显示警示标记 |
| 顾客反馈 | 反馈提交 | 选择线路，提交难度/动作问题和描述 |
| 顾客反馈 | 反馈汇总 | 按线路展示反馈数量和类型分布 |
| 线路管理 | 线路编辑 | 编辑线路名称、颜色、难度等级、开线人、拆线日期 |
| 线路管理 | 岩点关联 | 在墙面上勾选岩点归属某条线路 |
| 反馈复核 | 反馈列表 | 待复核反馈列表，显示线路、反馈内容、提交时间 |
| 反馈复核 | 复核操作 | 标记为保留/微调/下线，添加复核备注 |

## 3. 核心流程

```mermaid
flowchart LR

    C --> D["填写严重程度和备注"]
    D --> E["提交记录"]
    E --> F["岩点显示问题标记"]
```

### 3.2 顾客反馈与复核流程

```mermaid

    D --> E["保留 / 微调 / 下线"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰蓝 (#1e293b) 作为基底，搭配暖橙 (#f97316) 作为强调色，体现攀岩的力量感与活力
- **辅助色**：各难度等级使用标准化颜色标识（绿 V0-V1、蓝 V2-V3、紫 V4-V5、红 V6+）
- **按钮风格**：圆角中等 (rounded-lg)，悬停时有微妙的上浮和阴影效果
- **字体**：标题使用粗犷的无衬线字体，正文使用清晰易读的现代无衬线字体
- **布局风格**：左侧墙面示意图为主区域，右侧可折叠信息面板
- **图标风格**：使用 lucide-react 线性图标，保持简洁专业

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 墙面总览 | 墙面示意图 | SVG 网格背景、彩色岩点圆点、悬停高亮、点击交互 |
| 墙面总览 | 线路侧栏 | 卡片式线路列表、颜色标签、难度徽章、状态指示器 |
| 墙面总览 | 顶部导航 | 角色切换、页面切换 Tab、搜索框 |
| 巡场记录 | 问题弹窗 | 问题类型单选项、严重程度滑块、备注输入框、提交按钮 |
| 顾客反馈 | 反馈表单 | 线路选择、反馈类型、描述文本域、提交按钮 |
| 线路管理 | 编辑表单 | 颜色选择器、难度下拉、日期选择、岩点选择模式 |

### 4.3 响应式设计

- 桌面端：左右分栏布局，左侧墙面占 70%，右侧信息面板占 30%
- 平板端：上下布局，墙面在上，信息面板在下可折叠
- 移动端：单页流式布局，Tab 切换不同视图
- 触摸屏优化：岩点点击区域适当放大，按钮最小 44px

### 4.4 动效设计

- 页面加载：元素渐入 + 轻微位移， staggered 延迟
- 岩点悬停：缩放 1.1 倍 + 光晕效果
- 问题标记：脉冲呼吸动画，吸引注意
- 面板切换：平滑滑入滑出
- 表单提交：成功状态的微妙弹跳反馈
