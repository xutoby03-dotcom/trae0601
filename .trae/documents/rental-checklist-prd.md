## 1. 产品概述

租房看房评分清单 — 一款帮助租客系统化记录、评分和对比房源的工具，解决看完三套房就记混的痛点。目标用户为正在租房的年轻人和需要与室友/家人协商的合租群体。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 租客 | 无需注册，本地使用 | 添加/编辑/删除房源、评分、对比、导出 |

### 2.2 功能模块

1. **首页**：候选房源对比卡片、排序切换（总分/租金/通勤/风险提醒）、快捷操作入口
2. **添加/编辑房源页**：填写房源基础信息和上传照片
3. **房源详情页**：查看房源信息、检查清单评分和备注
4. **对比页**：选择 2-3 套房源并排对比，含一年总成本计算
5. **导出功能**：生成看房记录文档，方便分享

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 房源卡片列表 | 以卡片形式展示所有候选房源，显示小区、租金、总分、风险提醒标签 |
| 首页 | 排序控制栏 | 按总分、租金、通勤时间、风险提醒数排序 |
| 首页 | 空状态引导 | 无房源时引导用户添加第一套 |
| 添加/编辑房源页 | 基础信息表单 | 小区名称、月租金、押付方式（下拉）、面积、楼层、朝向（下拉）、通勤时间、中介费、可入住日期 |
| 添加/编辑房源页 | 照片上传 | 支持上传多张房源照片，本地预览 |
| 房源详情页 | 基础信息展示 | 展示房源所有基础字段 |
| 房源详情页 | 检查清单评分 | 9 项检查项（水压、采光、噪音、墙面、空调、冰箱、门锁、下水道、网络）各可打 1-5 分并写备注 |
| 房源详情页 | 总分与风险摘要 | 汇总检查清单分数，展示风险提醒 |
| 房源详情页 | 风险提醒标签 | 押金规则不清、合同期太长、家电老旧、楼下噪音、没有燃气 |
| 对比页 | 房源选择器 | 勾选 2-3 套房源加入对比 |
| 对比页 | 并排对比表 | 各维度并排展示（租金、面积、楼层、朝向、通勤、总分、检查项分数、风险标签） |
| 对比页 | 一年总成本 | 计算公式：月租金×12 + 押金 + 中介费，并排展示 |
| 导出 | 导出看房记录 | 生成文本/Markdown 格式的看房记录，包含所有房源信息和评分，可复制分享 |

## 3. 核心流程

用户打开应用 → 首页查看已添加的房源列表 → 点击「添加房源」填写基础信息和照片 → 进入房源详情页对检查清单逐项打分 → 系统自动计算总分和识别风险 → 回到首页按不同维度排序 → 选择 2-3 套房进入对比页查看并排对比和一年总成本 → 导出看房记录与室友/家人商量

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：工业实用风，像一份精心设计的检查清单/评分表，突出信息密度和可操作性
- **主色**：深炭灰 (#1C1917) 为底，暖橙 (#F97316) 作为强调色（呼应租房/家的温暖感）
- **辅色**：石板灰 (#78716C) 用于次要文字，浅灰 (#F5F5F4) 用于卡片背景
- **字体**：中文使用系统字体，数字和英文使用 DM Mono 等宽字体突出数据感
- **按钮风格**：圆角矩形，主按钮使用暖橙填充，次要按钮使用描边
- **卡片风格**：圆角 12px，微阴影，hover 时轻微上浮
- **图标**：Lucide 图标库，线性风格
- **风险标签**：红色系 (#EF4444) 背景，白色文字，小圆角胶囊形

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | 排序控制栏 | 水平标签组，暖橙高亮当前排序 |
| 首页 | 房源卡片 | 照片缩略图、小区名、租金大字、总分圆环、风险标签组、快捷按钮 |
| 添加/编辑房源页 | 表单 | 分组卡片式表单，下拉选择器，日期选择器，照片网格上传区 |
| 房源详情页 | 检查清单 | 每行一项：图标+名称+5星评分+备注输入，行间分隔线 |
| 房源详情页 | 风险标签组 | 水平排列的红色胶囊标签 |
| 对比页 | 对比表格 | 表头为房源名，左列为维度，高亮最优值 |
| 对比页 | 一年总成本卡片 | 大字展示金额，下方列出计算明细 |

### 4.3 响应式设计

- 桌面优先设计，最大宽度 1280px 居中
- 移动端自适应：卡片单列、对比表横向滚动
- 触摸优化：评分星星加大点击区域
