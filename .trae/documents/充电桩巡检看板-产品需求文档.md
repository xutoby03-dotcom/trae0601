## 1. 产品概述

社区电动车充电桩巡检看板系统，帮助物业提前发现充电桩故障（插座松动、屏幕不亮等），统一管理桩位档案、巡检记录、居民报修和维修流程，降低安全隐患，提升运维效率。

- 核心价值：主动巡检替代被动报修，故障可追溯，数据驱动运维决策
- 目标用户：物业巡检员、物业管理员、社区居民

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 物业管理员 | 桩位档案全量管理、巡检任务分配、报修审核、维修派单、数据统计查看 |
| 巡检员 | 执行巡检任务、查看桩位信息、提交巡检记录、标记异常 |
| 社区居民 | 查看充电桩状态、提交报修申请、查询报修进度 |

### 2.2 功能模块

1. **总览看板**：设备状态总览、告警提醒、待办任务、今日巡检概览
2. **桩位档案**：充电桩列表、详情查看、新增/编辑桩位信息
3. **巡检管理**：巡检任务、巡检记录表、异常项高亮
4. **报修中心**：居民报修提交、报修工单处理、进度追踪
5. **维修记录**：故障桩暂停预约、修复记录、配件管理
6. **数据统计**：故障率统计、使用高峰分析、未处理报修、长期低效桩分析

## 3. 核心流程

### 3.1 巡检流程
巡检员登录系统后查看当日巡检任务，逐个充电桩执行检查。每检查一项（屏幕、插座、漏保等）勾选状态，发现异常时拍照上传并标记问题。巡检完成后提交记录，异常项自动生成告警推送至管理员。

```mermaid
flowchart LR
    A["查看巡检任务"] --> B["选择充电桩"]
    B --> C["逐项检查：屏幕/插座/漏保/线缆/二维码/消防/堆物"]
    C --> D{发现异常?}
    D -->|是| E["拍照+标记异常项"]
    D -->|否| F["全部勾选正常"]
    E --> G["提交巡检记录"]
    F --> G
    G --> H["生成巡检报告"]
    H --> I{有异常?}
    I -->|是| J["推送管理员告警+创建维修工单"]
    I -->|否| K["记录归档"]
```

### 3.2 报修维修流程
居民通过报修入口选择问题充电桩和故障类型，提交工单。管理员审核后派单给维修人员，维修完成后记录配件和维修人，系统自动恢复充电桩预约功能并通知报修居民。

```mermaid
flowchart LR
    A["居民选择充电桩"] --> B["选择故障类型：充不进电/扣费异常/插头发热/二维码失效"]
    B --> C["补充描述+上传照片"]
    C --> D["提交报修"]
    D --> E["物业管理员审核"]
    E --> F["派单+标记故障桩暂停预约"]
    F --> G["维修人员现场修复"]
    G --> H["记录：故障原因/更换配件/维修人员"]
    H --> I["恢复预约功能"]
    I --> J["通知居民修复完成"]
    J --> K["居民评价确认"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：电力科技蓝 `#1E6FED`（信任、专业），搭配能源绿 `#10B981`（正常状态）和警示橙 `#F59E0B`（告警）、危险红 `#EF4444`（故障）
- **辅助色**：深夜蓝 `#0F172A` 作为深色区域背景，银灰 `#94A3B8` 作次要文字
- **按钮风格**：圆角 8px，主按钮带微渐变和轻阴影，hover 有上浮效果
- **字体**：标题使用 `Space Grotesk` 现代几何无衬线字体，正文使用 `PingFang SC` / `Microsoft YaHei`
- **布局**：左侧侧边栏导航 + 顶部面包屑 + 主内容卡片式网格布局
- **图标风格**：统一使用 `Lucide` 线性图标，与蓝绿主题色匹配

### 4.2 视觉特色
- 顶部状态栏使用深色渐变背景，数据卡片带彩色进度条
- 充电桩卡片状态用发光色边框指示（绿色=正常，红色闪烁=故障）
- 告警卡片带脉冲动画，吸引注意力
- 统计图表使用渐变色填充，动画加载效果
- 巡检执行页面采用大尺寸勾选框，便于移动端操作

### 4.3 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 总览看板 | 设备状态卡片 | 四色渐变图标卡片（蓝/绿/橙/红）+ 大数字 + 环比变化小箭头 |
| 总览看板 | 楼栋热力图 | 网格布局楼栋缩略图，按状态着色，hover 显示详情浮层 |
| 桩位档案 | 充电桩卡片 | 圆角卡片，上方缩略图，下方编号+楼栋标签，右下角状态徽章 |
| 巡检执行 | 检查项列表 | 分组卡片式，每一项配大图标+三态按钮（正常/异常/跳过） |
| 报修中心 | 工单列表 | 横向标签筛选 + 卡片式工单，左侧竖条色带指示状态 |
| 数据统计 | 图表区 | 折线图/柱状图/热力图组合，支持时间范围切换 |

### 4.4 响应式设计
- **桌面端（优先）**：1440px 宽度基准，侧边栏固定 240px，主内容区 2-4 列网格自适应
- **平板端（768-1024px）**：侧边栏折叠为图标导航，主内容 2 列布局
- **移动端（<768px）**：顶部汉堡菜单，巡检和报修页面单列大按钮布局，拍照按钮固定底部
- 巡检执行页面针对移动端优化：大尺寸触控区域，拍照按钮悬浮
