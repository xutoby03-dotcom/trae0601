## 1. 产品概述

沙盘版本管理系统是专为培训教室沙盘推演场景设计的版本管理工具，解决讲师在推演过程中棋子摆法变更后难以回溯的痛点。讲师可保存场景快照、对比版本差异、回放推演步骤，提升培训效率和教学质量。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 讲师 | 免登录（本地存储） | 创建/编辑/删除场景版本、对比版本差异、回放推演步骤 |

### 2.2 功能模块

1. **沙盘编辑区**：可视化棋盘、棋子拖拽摆放、角色设置、资源配置、触发条件编辑
2. **版本管理面板**：版本列表、保存新版本、版本重命名、版本删除、版本切换
3. **版本对比视图**：双版本并排对比、差异高亮标记（新增/撤掉/换角色/条件变化）
4. **推演回放功能**：步骤时间线、播放/暂停/速度控制、逐帧步进

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 顶部工具栏 | 场景名称编辑、保存版本按钮、版本对比切换、回放模式切换 |
| 主页面 | 沙盘编辑区 | 网格棋盘、棋子拖拽、选中棋子属性面板 |
| 主页面 | 右侧版本面板 | 版本列表、版本操作（重命名/删除/对比） |
| 主页面 | 底部回放控制条 | 播放/暂停、速度调节、进度条、步骤显示 |
| 主页面 | 属性编辑面板 | 角色含义设置、资源数量配置、触发条件编辑 |

## 3. 核心流程

讲师打开沙盘管理页 → 在棋盘上摆放棋子并配置属性 → 保存当前场景为一个版本 → 继续推演并保存多个版本 → 选择两个版本进行对比 → 查看差异标记 → 切换到回放模式 → 按时间线回放推演步骤。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝炭灰背景（#1a1f2e），军事指挥室风格
- **强调色**：琥珀金（#f59e0b）用于版本标记，翠绿（#10b981）用于新增，赤红（#ef4444）用于撤掉，靛蓝（#6366f1）用于角色变更
- **按钮风格**：直角切角设计，硬朗军事风，悬停时有发光描边
- **字体**：显示字体用 Orbitron（科技感），正文字体用 Noto Sans SC
- **布局风格**：三栏布局 - 左侧属性面板 + 中央沙盘区 + 右侧版本列表
- **视觉元素**：网格线棋盘、像素风格棋子、扫描线动效、全息投影质感

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主页面 | 顶部工具栏 | 深色渐变背景、琥珀金标题文字、切角按钮、发光分隔线 |
| 主页面 | 沙盘编辑区 | 网格棋盘背景、可拖拽棋子、选中高亮光环、坐标标尺 |
| 主页面 | 版本列表面板 | 卡片式版本项、时间戳显示、当前版本标记、悬停发光效果 |
| 主页面 | 对比视图 | 左右分栏、差异点连线、颜色编码图例 |
| 主页面 | 回放控制条 | 深色玻璃质感、进度扫描线、霓虹按钮、步进控制 |

### 4.3 响应式

桌面端优先设计，支持 1280px 及以上分辨率。平板设备可自适应，棋子尺寸和面板宽度随屏幕调整。不针对移动端优化。

### 4.4 动效设计

- 棋子拖拽：幽灵预览 + 落下回弹动画
- 版本保存：扫描线从上至下扫过棋盘的粒子效果
- 对比差异：脉冲闪烁高亮，逐步显示差异点
- 回放模式：时间线扫描光效，棋子移动有轨迹残影
