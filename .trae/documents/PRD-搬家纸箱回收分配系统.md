## 1. 产品概述
搬家纸箱回收分配系统，旨在解决朋友间搬家后纸箱闲置浪费的问题，实现纸箱的循环利用，既环保又经济。
- 主要用途：管理纸箱档案、追踪借还状态、可视化看板监控，在朋友圈子内实现纸箱资源的高效流转
- 目标用户：有搬家需求的朋友群体，希望减少包装材料浪费的环保人士
- 产品价值：减少纸箱浪费、节省搬家成本、增进朋友间互助、实践绿色生活

## 2. 核心特性

### 2.1 用户角色
本系统面向朋友圈子内的所有用户，不设复杂权限区分，采用简单直观的社区化管理模式。

| 角色 | 登记方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 姓名+小区登记 | 登记纸箱、预约领取、归还登记、查看看板、所有操作 |

### 2.2 功能模块
1. **看板首页**：数据概览、可借数量统计、预约冲突提示、待归还提醒、报废箱统计、最近搬家清单
2. **纸箱档案管理**：纸箱列表、新增/编辑纸箱、纸箱详情、照片上传、状态变更
3. **借还管理**：预约领取、归还检查、使用记录追踪、预约冲突检测
4. **分类筛选**：按用途分类（大件箱/衣柜箱/书箱）、按状态筛选、按小区筛选

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|----------|----------|
| 看板首页 | 数据统计卡片 | 显示可借数量、预约中、待归还、报废箱总数，每个卡片带图标和趋势提示 |
| 看板首页 | 预约冲突看板 | 高亮显示同一时段多人预约同一纸箱的冲突情况，支持快速调解 |
| 看板首页 | 待归还清单 | 列表展示即将到期/已逾期的待归还纸箱，显示借用人和预计归还日期 |
| 看板首页 | 报废箱看板 | 统计已报废纸箱，显示报废原因（受潮/破洞/胶带残留严重） |

| 纸箱档案页 | 纸箱详情 | 完整档案信息、借还历史记录、状态时间线、照片画廊 |

## 3. 核心流程

### 3.1 纸箱登记流程
用户搬家后整理可用纸箱 → 在系统登记纸箱档案（尺寸、承重、来源、照片）→ 系统自动初始化状态为"可借用" → 纸箱进入可借库存

### 3.2 预约领取流程
用户浏览可借纸箱 → 选择需要的纸箱提交预约 → 系统检测该时段是否有冲突 → 无冲突则预约成功 → 到预约日期领取并确认

### 3.3 归还检查流程
用户归还纸箱 → 管理员进行归还检查（受潮/破洞/胶带残留）→ 根据检查结果更新状态（可继续使用/需修复/报废）→ 使用次数+1 → 完成归还

### 3.4 报废处理流程
归还检查时发现纸箱严重损坏 → 标记为报废 → 记录报废原因 → 纸箱从可借库存移除 → 进入报废统计

```mermaid
    B --> C["用户预约领取"]

    J --> K{"是否可继续使用？"}
    K -->|是| L["状态：可借用", "使用次数+1"]
    K -->|需修复| M["状态：待修复"]
    K -->|否| N["状态：报废", "记录报废原因"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：温暖的环保绿色系（#2E7D32 深绿为主色，#81C784 浅绿为辅助色），搭配温暖的纸皮棕色（#8D6E63），呼应纸箱和环保主题
- **强调色**：橙红色（#E64A19）用于警告和冲突提示，天蓝色（#0288D1）用于预约状态
- **按钮风格**：圆角按钮（12px），带有微妙的阴影效果，hover时轻微上浮
- **字体**：标题使用"ZCOOL XiaoWei"中文艺术字体营造亲和力，正文使用"Inter"现代无衬线字体保证可读性
- **布局风格**：卡片式布局，圆角边框，柔和阴影，大量留白营造呼吸感
- **图标/emoji风格**：使用纸箱、卡车、日历、笑脸等emoji增强趣味性，统一使用Font Awesome图标

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|----------|--------|
| 看板首页 | 统计卡片区 | 4个大卡片横向排列，每个卡片有渐变背景、大号数字、趋势小箭头、emoji图标，悬停时有上浮动画 |
| 看板首页 | 看板网格 | 2×2网格布局展示4个功能看板，每个看板有独立标题栏、滚动列表、状态标签 |
| 看板首页 | 搬家日历区 | 时间线样式展示最近搬家计划，日期标签+朋友头像+小区信息，有渐入动画 |
| 纸箱档案页 | 筛选工具栏 | 分类筛选按钮组（大件箱/衣柜箱/书箱/全部）、状态筛选下拉框、搜索框，粘性顶部 |
| 纸箱档案页 | 纸箱卡片网格 | 响应式网格（桌面4列），卡片含缩略图、尺寸标签、状态徽章、使用次数标记 |
| 纸箱档案页 | 抽屉式表单 | 点击新增从右侧滑出表单，分步填写（基本信息→照片→确认），带进度指示 |
| 借还管理页 | 预约列表 | 时间线布局，显示预约状态流转，不同状态用不同颜色标记 |
| 借还管理页 | 归还检查表 | 评估项用滑块或星级评分，整体评估结果用大图标强调（绿色✓可继续/黄色⚠需修复/红色✕报废） |

### 4.3 响应式
- 采用桌面优先设计（Desktop-first）
- 桌面端：4列网格、侧边导航、充足留白
- 平板端：2列网格、顶部导航、适当压缩间距
- 移动端：单列布局、底部Tab导航、卡片全屏宽度、触摸优化（按钮≥44px）
- 所有交互元素支持触摸操作，重要功能有触摸反馈

### 4.4 动效设计
- 页面加载：卡片依次淡入（staggered animation，每个延迟50ms）
- 状态变更：状态徽章颜色过渡动画，数字变化有滚动效果
- 抽屉滑入：从右侧平滑滑出，带遮罩层淡入
- 悬停效果：卡片轻微上浮（translateY(-4px)），阴影加深
- 数据更新：看板数据刷新时有脉冲动画提示
