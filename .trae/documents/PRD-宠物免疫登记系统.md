## 1. 产品概述

小区宠物免疫登记管理系统，解决物业临检时疫苗证明查找困难、各宠物接种时间不统一的问题。通过信息化手段建立宠物档案与疫苗记录，实现免疫到期提醒、合规状态自动判定、多维度筛选统计，提升物业管理效率。

- 核心目标：集中管理宠物档案和免疫记录，临检快速查询证明，自动预警到期/过期疫苗
- 目标用户：小区物业管理人员、宠物登记专员
- 产品价值：减少纸质证明翻找时间 80%，确保临检 100% 可查，自动提醒避免免疫过期

## 2. 核心功能

### 2.1 用户角色
| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 物业管理员 | 系统内置账号 | 宠物档案 CRUD、疫苗记录 CRUD、看板筛选统计、导出未补证明名单 |

### 2.2 功能模块
1. **首页看板**：统计概览卡、到期提醒区、过期警示区、本月到期数、未补证明名单
2. **宠物档案管理**：新增/编辑/删除宠物档案，含照片上传
3. **疫苗记录管理**：按宠物关联接种记录，含证明照片上传、到期自动计算
4. **多维度筛选**：按楼栋、宠物类型、到期状态（合规/临期/过期/未接种）筛选
5. **数据统计**：本月到期数量、各楼栋宠物分布、未补证明名单导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页看板 | 统计概览区 | 展示宠物总数、已合规数、临期数、过期数、未接种数卡片 |
| 首页看板 | 到期提醒区 | 30天内即将到期的疫苗列表，按到期日升序排列 |
| 首页看板 | 过期警示区 | 已过期疫苗单独标红警示，显示超期天数 |
| 首页看板 | 未补证明名单 | 缺少证明照片的疫苗记录列表，可快捷跳转补录 |
| 首页看板 | 筛选工具栏 | 楼栋下拉、宠物类型下拉、到期状态下拉、搜索框 |

## 3. 核心流程

物业管理员日常使用流程：
1. 登录系统 → 进入首页看板
2. 查看到期提醒区 → 通知相应业主接种
3. 业主完成接种 → 找到对应宠物档案 → 新增疫苗记录 → 上传证明照片
4. 临检时 → 按楼栋筛选 → 快速调出该栋所有宠物合规状态
5. 发现未补证明 → 在未补名单中点击 → 跳转补录证明照片
6. 月末统计 → 导出本月到期数量和未补证明名单

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：森林绿 #16a34a（健康、信任、自然），搭配暖橙 #f97316 作为临期警示，警示红 #dc2626 作为过期标记
- **辅助色**：石板灰 #475569 为中性色，米白 #f8fafc 为背景
- **按钮风格**：圆角 10px，主按钮实色填充配微阴影，悬停放大 1.02 倍
- **字体方案**：展示字体用 **Noto Sans SC**（现代中文无衬线），数据数字用 **JetBrains Mono** 等宽对齐
- **布局风格**：卡片式栅格布局，顶部通栏导航 + 左侧筛选栏 + 主内容区三栏结构
- **图标**：Lucide 线性图标，状态用彩色标签（Badge）配合 emoji 强化感知（🐶🐱💉✅⚠️❌）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素与动效 |
|----------|----------|---------------|
| 首页看板 | 统计卡片组 | 5 张横向排列卡，渐变背景 + 悬浮光晕，入场 stagger 动画 |
| 首页看板 | 到期提醒区 | 列表项左侧色条（橙=临期 / 红=过期），hover 背景微上浮 |
| 首页看板 | 筛选工具栏 | 下拉框胶囊造型，多选中时标签堆叠，联动实时过滤 |
| 宠物档案 | 档案卡片网格 | 照片圆角裁切在上，合规状态徽标浮于右上角，hover 轻微放大 |
| 疫苗记录 | 时间线布局 | 左侧竖线 + 圆点，每次接种一条记录，证明照片可点击放大 |
| 表单弹窗 | 模态对话框 | 半透明模糊背景遮罩，弹窗下拉出现 + 内容淡入 |

### 4.3 响应式
- 桌面优先设计（最小宽度 1280px）
- 平板（768px–1024px）：筛选栏收起为顶部横向标签，卡片缩为 2 列
- 移动端（<768px）：单栏堆叠，统计卡纵向排列，表格换为卡片列表

### 4.4 动效细节
- 页面加载：统计卡片 stagger 100ms 依次下滑出现
- 状态标签：过期状态标签带呼吸闪烁动画（2s 循环）
- 筛选切换：结果区 fade 200ms 过渡
- 按钮点击：scale 0.97 → 1.0 的弹性反馈
