## 1. 产品概述

简谱乐谱编辑器是一款专为老歌民谣爱好者设计的数字记谱工具，支持简谱（数字谱）的快速输入、编辑、播放和导出，让用户能够轻松记录和分享喜爱的歌曲。

- 核心目标：降低记谱门槛，提供简洁高效的简谱创作环境
- 目标用户：老歌民谣爱好者、音乐教学、业余音乐人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册，直接使用 | 所有编辑、播放、导出功能 |

### 2.2 功能模块

1. **主编辑界面**：乐谱编辑区、工具栏、控制面板
2. **乐谱渲染**：横向简谱显示，支持八度标记、时值横线、多声部
3. **输入系统**：工具栏点击 + 键盘快捷键输入
4. **歌词编辑**：每个音符对应歌词输入
5. **播放预览**：WebAudio 播放，BPM 控制，滚动同步高亮
6. **导出功能**：PNG 图片和 MusicXML 格式导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 编辑器主页 | 顶部工具栏 | 音符时值选择（全/半/四分/八分/十六分）、BPM 控制、播放控制 |
| 编辑器主页 | 乐谱编辑区 | 横向简谱显示，五线谱式布局，支持点击编辑、键盘输入 |
| 编辑器主页 | 声部切换 | 主旋律（蓝色）+ 和声（绿色）两声部切换显示 |
| 编辑器主页 | 歌词编辑区 | 每个音符下方可输入中英文歌词 |
| 编辑器主页 | 导出面板 | PNG 导出、MusicXML 导出按钮 |

## 3. 核心流程

### 用户记谱流程

用户打开编辑器 → 选择音符时值 → 用数字键 1-7 输入音符 → 上下箭头调整八度/升降半音 → 空格输入休止符 → 点击音符下方输入歌词 → 切换声部输入和声 → 点击播放预览 → 导出乐谱

```mermaid
    D --> E["空格输入休止符"]
    E --> F["输入对应歌词"]
    F --> G["切换声部输入和声"]
    G --> H["播放预览"]
    H --> I["导出PNG/MusicXML"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝 (#1e3a5f) 作为主色，搭配暖黄 (#f59e0b) 作为强调色
- **辅助色**：主旋律用蓝色 (#3b82f6)，和声用绿色 (#10b981)
- **背景**：米白色纸张质感 (#faf8f5)，营造乐谱氛围
- **按钮风格**：圆角矩形，轻微阴影，悬停有缩放效果
- **字体**：衬线字体用于音符数字，无衬线字体用于界面文字
- **布局风格**：顶部工具栏 + 中间大编辑区 + 底部状态栏，简洁专业

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 编辑器主页 | 顶部工具栏 | 时值按钮组、BPM 滑块、播放/暂停/停止按钮、导出按钮 |
| 编辑器主页 | 乐谱编辑区 | 浅米色背景，黑色音符数字，蓝色主旋律，绿色和声，播放时黄色高亮 |
| 编辑器主页 | 歌词编辑 | 音符下方灰色输入框，点击激活编辑 |
| 编辑器主页 | 声部指示器 | 右上角声部切换标签，当前声部高亮 |

### 4.3 响应式设计

- 桌面端优先，编辑区自适应宽度
- 最小宽度 1024px，保证乐谱显示空间
- 移动端可查看但编辑功能受限

### 4.4 交互细节

- 音符悬停时放大 1.1 倍，显示可点击状态
- 播放时当前音符黄色高亮，编辑区自动滚动
- 键盘输入有视觉反馈（按钮闪烁）
- 歌词输入回车自动跳到下一个音符
